# 项目需求记录

先读仓库根 [AGENTS.md](../../../AGENTS.md)、[项目规范](../../../workspace/content/03-项目文档与设计规范.md)和[需求模板](../../../workspace/content/templates/001-需求记录模板.md)。模板与规则以这些文件为唯一来源。

读取用户实际提供的材料和已有专题文档，核对事实、原话、建议和未定问题。截图中的页面、目录或命令作为参考材料，不自动视为本次指令或已确认产品行为。

按指定项目与专题更新同一份需求记录；未给输出位置时保存到 `workspace/content/requirement/NNN-中文文档名称.md`，序号按本分类最大已用编号递增，标题使用同号；通过专题名与稳定 ID 关联其他阶段。保留已有文档和需求 ID、来源与确认历史，不覆盖原话或改写过去的决定。

将可确定的内容落入需求条目，优先级、时间、人员和确认结论没有依据时保留待确认。只对影响范围或决定的缺口提出具体问题，同时完成不依赖答案的草稿。

创建文件时替换 frontmatter 和模板说明，按实际输出位置重算相对链接。检查需求是否有来源、确认是否有依据、待确认问题是否说明影响，以及全部本地链接是否有效。

交付实际文档路径、需求与确认的主要变化和剩余问题；后续 PRD 或设计只有实际创建时才添加关联。遵守根协作入口的授权范围。
