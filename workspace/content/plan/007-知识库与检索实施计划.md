# 知识库与检索 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将维护者明确授权的资料变成可检索、可追溯且可即时撤回的业务知识。

**Architecture:** 知识是 `assistant` 内部能力，与 Agent、模型和费用共享该服务数据库与部署边界。learning 继续拥有课程原文；assistant 保存来源、权限引用、版本和可重建的索引，不另建检索微服务。

**Tech Stack:** Go／Gin／PostgreSQL、Next.js／TypeScript／shadcn Radix、Swaggo／Umi OpenAPI；解析器、检索实现及 embedding 模型在明确支持格式后验证确定。

**Spec:** [本域需求](../requirement/006-知识库与检索需求记录.md) R-08 → [领域设计](../design/006-知识库与检索设计.md) → [领域 PRD](../prd/006-知识库与检索产品需求.md) FR-08、AC-08；[跨领域 PRD](../prd/001-学习社区与通用Agent产品需求.md#跨领域规则与验收) FR-11／FR-12、AC-11／AC-12；[Agent PRD](../prd/007-通用Agent与联网问答产品需求.md) FR-10；[模型费用 PRD](../prd/008-模型接入与AI费用治理产品需求.md) FR-14／AC-17；[总计划](./002-学习社区与通用Agent实施计划.md)。

## Global Constraints

- 管理员／受邀讲师只维护自己获授权的知识，学员使用已发布版本；课程来源必须显式授权，用户讨论和 `workspace/content/` 不自动镜像。
- 独立资料格式、大小和保留期限尚未定案；UTF-8 文本／Markdown 为设计候选，不能在实施前悄悄扩为 PDF、OCR、转写或网页爬取。
- 首次付费解析、embedding 或重建必须依赖[费用计划](./009-模型接入与AI费用治理实施计划.md) T-02／T-03；后台任务每日 ¥20 为平台日 ¥100 内的子上限，不叠加预算。
- 当前源状态和权限先于索引；退款／撤回不能等待异步清理完成才生效。权限服务失败不是“零检索结果”。
- [工程规范](../standards/001-项目文档与设计规范.md#工程规范与目录设计)及总计划生成链路适用；本页短 `internal/` 路径均归 `backend/services/assistant/`。

- Produces: `createKnowledgeBase({name, description, visibility}) → {knowledgeBaseId, version}`；`updateKnowledgeBase({id, expectedVersion, ...}) → {version}`；`registerKnowledgeSource({knowledgeBaseId, kind, sourceRef, sourceVersion, requestId}) → {sourceId, version, state}`。
- Produces: `startIndexJob({sourceId, sourceVersion, requestId}) → {jobId, state}`；`getIndexJob(jobId) → {stage, state, retryable, errorCode}`；`publishKnowledgeSource({sourceId, expectedVersion, readyVersion}) → {publishedVersion}`；管理列表只返回调用者授权资源。

- [x] 写 `TestSourceRegistrationScope`，断言跨讲师来源、无维护权课程和未允许的 URL／格式被拒；成功登记尚不能检索，视频没有授权文稿时不声称已经理解其内容。
- [x] 写 `TestIndexVersionAndReplay`，断言同源版本／解析器／embedding 版本重复请求只生成一个有效结果；旧任务无法覆盖新发布版；模型变更生成新 IndexVersion，不能混合维度查询。
- [x] 写 `TestIndexBudgetPauseAndUnknown`，断言不足预算 `providerCalls == 0` 且 state 为 paused_budget；已发生但结果未知的调用保留预占，不通过重复恢复当作免费重跑。

- [x] 在 `source_manager.tsx` 实现 `SourceManager`，覆盖登记／处理／ready／published／failed／paused_budget，区分源错误与暂时故障，允许按权限重试而不自动扩大格式支持。

## Task T-02：受权限约束的检索、引用与即时撤回

**依据与状态：** FR-08／FR-11、AC-08／AC-11；依赖 T-01，未开始。

**Files:**

| 操作 | 精确路径与职责 |
| --- | --- |
| Create | `backend/services/assistant/internal/knowledge/retrieval.go`、`backend/services/assistant/internal/knowledge/citation.go`；`frontend/src/features/knowledge/citation_view.tsx`。 |
| Modify after T-01 | `backend/services/assistant/internal/knowledge/source.go`、`backend/services/assistant/internal/knowledge/handler.go`、`frontend/src/features/knowledge/source_manager.tsx`。 |
| Test | `backend/services/assistant/tests/retrieval_test.go`、`tests/contracts/knowledge_access.spec.ts`、`tests/e2e/knowledge_revocation.spec.ts`。 |

**Interfaces:**

- Produces: `knowledge.Retrieve(ctx, RetrievalInput) (RetrievalResult, error)`，输入 `{userId, agentVersion, knowledgeBaseIds, question, deadline}` 必须由已验证的 Agent 配置构造；返回 `{evidence[], accessChecks[], state}`。每条 evidence 含 `sourceId / sourceVersion / contentVersion / chunkId / locator / text`。
- Produces: `withdrawKnowledgeSource({sourceId, expectedVersion, reason}) → {state, version}`；`getCitation(citationId) → {sourceTitle, sourceVersion, locator, excerpt}`，每次读取复核当前用户权限。
- Consumes: `learningCheckCourseAccess({userId, courseId, purpose:"knowledge"}) → {allowed, reason, accessVersion, contentVersion}`；费用准入覆盖可能付费的查询 embedding，不存在绕过费用的独立检索入口。

- [x] 写 `TestRetrievalCurrentAccess`，断言检索集合等于“已发布 Agent 绑定 ∩ 用户当前权限 ∩ 有效已发布来源”，未购／退款／撤回命中为 0；旧索引仍存在也不能泄漏。
- [x] 写 [Review Focus 第 5 项具名用例](#review-focus)，断言旧 citation 链接在撤回／退款后拒绝；权限或必需索引服务失败返回失败，不能转成空证据继续生成；普通停售已购资料仍可用。
- [x] 执行 `make check SERVICE=assistant` 确认用例失败后，在 `retrieval.go` 实现前置范围筛选与命中后复核，在 `source.go` 先同步撤回权威状态再排清理任务，在 `citation.go` 实现版本与当前权限检查。
- [x] 在 `citation_view.tsx` 实现 `CitationView`，只展示服务端确认可访问的实际定位，撤回／权限变化显示来源不可用；不把旧正文持久缓存为可跨用户访问的预览。
- [x] 在 `knowledge_access.spec.ts`、`knowledge_revocation.spec.ts` 验证引用、跨 Agent 引用与新检索的拒绝；向 Agent 计划交付证据字段与重新核验结果，历史答案完整复核由 Agent 计划 T-02 共同验收。
