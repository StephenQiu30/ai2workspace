### 开工顺序与交接

| 顺序 | 可开工范围 | 交接条件 |
| --- | --- | --- |
| 1. 建立试点基线 | 010 T-01 从统一单体和工作区鉴权建立试点 | 在隔离空库验证统一 SQL、工作区授权、统一 Swagger 和客户端生成 |
| 2. 交付设定与素材 | 010 T-02 的设定版本和 T-03 的素材登记可并行，T-04 汇合权限与撤回 | 制作、检索和发布能共同引用确定版本，工作区和用途校验可复测 |
| 3. 推进制作和检索 | 011 先完成手工制作与 MP4 合成。012 可在设定与用途契约到位后并行，剧本索引等待 011 T-01 的固化版本 | 011 向发布交接已审成片，012 向 Agent 交接可核对且已鉴权的引用 |
| 4. 接入 Agent 与发布 | 013 在制作候选接口和 RAG 引用稳定后联调。014 拿到已审成片和发布许可即可验证公开快照 | Agent 能恢复并追踪费用，发布提供稳定作品 ID、指定版本的可交付状态和访问接口 |
| 5. 并行二创与交易 | 015 与 016 各自在发布契约上开发，授权发布和付费访问分别回到作品联调 | 015 完成一次退回重交。016 从原订单完成核验、开权、实际访问和售后模拟 |

发布前按架构设计 §4 验证统一数据库、各模块任务执行及产品链路。按实际部署准备 Kubernetes 与遥测基线，完成数据库及 COS 恢复演练，并校验回退能保全付款和费用事实。用隔离环境先联合走通三条路径，外部模型、真实支付和退款分别按已获授权的账号、预算和环境执行。七份计划目前为草案，任务尚未执行。

首版建议用一个自有 IP 和一集 30–60 秒动态漫贯通三条路径：

- **制作**　IP 设定与素材 → 剧本定稿 → 分镜与镜头制作 → 审片 → 平台合成并导出 → 正式发布。RAG 提供有权限的设定与证据，制作 Agent 提供候选与检查意见，由制作人员确认采用。
- **参与**　从公开首页进入作品 → 观看正片或试看、阅读制作拆解 → 参与作品讨论或提出二创 → 投稿、反馈与修订。
- **商业**　为一项自有作品商品建单 → 核验付款 → 开通权益 → 确认内容实际可访问 → 对账与适用售后。在创作、发布、二创和交易的对应 PRD 中记录可观察结果。

方向已确认，单集规格、首个 IP、授权确认人、素材许可、生成／渲染服务及真实支付条件仍待评审。验收覆盖功能、权限、版本、故障恢复及相关质量要求。评审、实施和发布按[项目生命周期](./01-项目文档与设计规范.md#需求设计与验收的生命周期)记录。
