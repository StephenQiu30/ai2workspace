## 1. 摘要

让管理员和受邀讲师维护能够被通用 Agent 使用的业务知识，明确资料来源、版本、可用范围与撤回结果。学员应通过已发布 Agent 获得自己有权访问的证据，而不是继承资料维护者的权限。首版聚焦资料管理、授权检索和可追溯引用。

## 3. 背景

用户希望根据不同知识库配置通用 Agent，课程上下文和平台知识是应用场景。当前没有业务入库或检索实现，也没有准确率、吞吐或满意度基线；本页定义应可观察的产品行为。知识库网站的 Markdown 正文不默认同步为业务知识，课程视频上传不表示已实现转写或视频理解。

## 4. 目标与成功标准

| 目标 | 可观察的首版结果 | 验收归属 |
| --- | --- | --- |
| 资料维护可完成 | 有权者登记、更新、查看处理结果、显式发布或撤回；失败可分辨并有恢复入口 | AC-08 |
| 回答依据可追溯 | 只有有效已发布来源参与检索，实际来源和版本可定位；旧处理任务不能覆盖新版本 | AC-08，与 Agent 引用展示联合验证 |
| 权限与费用不旁路 | 未购／退款／撤回后不能从旧检索、引用或历史读取受限内容；付费入库受统一预算限制 | 共同 AC-11、AC-12 的本域贡献；费用域 AC-17 |

本轮没有实测质量目标。正式启用前使用明确授权且覆盖实际问题的样本核验检索与引用，不能以固定样本或文档构建通过代替真实课程质量验证。

## 5. 目标用户与细分

**知识维护者**是管理员或受邀讲师，需要整理、更新并控制自己获授权资料的可用范围；**知识使用者**是通过已发布 Agent 求助的学员，需要知道答案依据并只看到自己有权读取的内容。使用者首版不拥有个人知识库编辑或 Agent 发布能力。

## 6. 价值主张

| 维度 | 知识维护者 | 知识使用者 |
| --- | --- | --- |
| Who | 整理平台或课程知识的管理员／受邀讲师 | 向通用 Agent 询问学习或平台问题的学员 |
| Why | 保持资料来源、版本和授权清晰，更新失败时能恢复 | 获取与当前学习权限一致、能够核对来源的帮助 |
| What before | 尚无维护流程访谈；资料分散或重复答疑是待验证假设 | 尚无使用基线，不宣称已发现具体检索错误率 |
| How | 明确来源登记、处理状态、版本发布、引用定位和撤回 | Agent 消费授权检索证据，来源可查看，失效内容不继续暴露 |
| What after | 知道哪些资料当前可用、何时被撤回，失败不污染有效版本 | 可核对证据，并理解资料不足或不可访问的原因 |
| Alternatives | 手工整理资料或通用知识管理工具；本方案连接现有课程权限 | 自行搜索原资料或询问讲师；是否改善学习体验需真实试用 |

价值假设是让可管理的来源和可核对的证据共同支持学习问答；通过资料维护闭环、版本正确和权限验收验证，而不以接入某个向量数据库作为产品成功。

## 7. 产品方案

### 7.1 主要流程与交互

1. 维护者创建知识库，登记允许类型的独立资料或经课程域授权的来源；界面说明支持范围，未支持的资料不能假装导入成功。
2. 查看处理阶段、失败原因和可恢复动作；资料登记、处理完成、发布可用是不同结果，处理完成不会自动向学员开放。
3. 有权者选择处理完成且来源仍有效的版本发布。更新形成新版本；新版本失败保留原有效版本，旧任务不能覆盖较新发布结果。
4. Agent 取得已发布配置允许的知识范围，按当前使用者权限检索；返回实际来源、版本与定位，使用者查看引用时仍重新验证访问权。
5. 维护者撤回来源后立即停止新的检索与引用访问，后台清理可继续重试。历史答案重新读取与新答案交付的权限复核由 Agent 联合完成。

界面覆盖无资料、处理中、处理完成未发布、已发布、失败、无权、已撤回和预算暂停。无有效证据与知识服务异常必须区分，不能把失败显示为成功的空检索。

### 7.2 首版功能、规则与验收

| 行为 ID | 来源 | 产品行为与规则 | 验收 ID 与可观察结果 |
| --- | --- | --- | --- |
| FR-08 业务知识库 | 本域需求 R-08 | 管理资料导入、来源、版本、可见范围、处理状态和撤回；课程资料需显式授权接入，用户讨论不自动成为可信知识 | AC-08：导入失败可重试；未发布版本不参与回答；删除、撤回或权益失效后，新检索及历史会话重新读取不泄露受保护内容 |

以下是 FR-08 的可观察细化，承接既有设计和计划，具体输入格式等仍按第 7.4 节处理：

- 维护者只能登记自己获授权的来源，不能因有讲师角色而绑定他人课程；扩大可见范围仍需核对来源权限。课程原文只由课程域维护，不建立第二个可编辑权威。
- 实际可检索范围同时满足已发布 Agent 的绑定、用户当前访问权和来源当前有效且已发布；资料维护权不直接授予学员使用权。课程域综合内容状态和交易权益给出当前访问结论，不能仅看历史购买记录。
- 重复处理不会重复发布；失败和旧任务不会覆盖新版本。更换检索模型或重建索引不能将未经验证的结果直接作为当前有效版本，也不能绕过来源撤回。
- 引用指向实际使用的来源、版本和位置，不伪造全文依据。来源撤回或访问权失效时，旧引用、另一 Agent 和历史会话不能成为旁路；普通停售仍保留合法已购的相应知识访问。
- 来源状态先阻断使用，派生索引清理随后完成；清理失败不重新放行。必要授权或知识服务不可用时明确失败，不将其当成“没有相关资料”继续冒充正常课程依据。

### 费用与回答边界

付费解析、embedding、索引重建及查询 embedding 必须在调用前通过[模型与 AI 费用 PRD](./008-模型接入与AI费用治理产品需求.md#ai-费用控制)的准入与核对能力；后台额度属于平台总额内的子上限，不是额外预算。缺预算可暂停恢复；结果未知的已发生调用保留费用核对，不通过反复重试当作免费任务。此处不重复配置额度或改变费用域验收。

本域提供检索依据，不另设绕过[Agent 每答联网规则](./007-通用Agent与联网问答产品需求.md#联网搜索失败策略)的正常问答入口。搜索失败是否生成、生成超时、答案完成与取消均由 Agent 领域定义；知识检索失败须向其明确返回失败，不能伪装成功零结果。

### 7.3 跨领域职责与技术约束

| 关联领域 | 输入 / 权威边界 | 本域交付与联合验收 |
| --- | --- | --- |
| [账号 PRD](./002-账号与访问控制产品需求.md) | 当前身份、角色、账号状态 | 拒绝无权维护及停用账号访问，资源归属单独校验 |
| [课程 PRD](./003-课程与媒体学习产品需求.md)和[交易 PRD](./004-交易退款与权益产品需求.md) | 授权来源、内容版本与当前访问结论，区分普通停售和必须撤回 | 只取经授权资料；退款／撤回后及时拒绝，保留仍有效的其他购买授予 |
| [Agent PRD](./007-通用Agent与联网问答产品需求.md) | 已发布实例与问题；会话和回答归 Agent | 交付真实证据／引用并支持再次核验；历史答案访问与生成前后复核联合验收 |
| [费用 PRD](./008-模型接入与AI费用治理产品需求.md) | 允许模型、预算预占与费用核对 | 首个付费入库或查询前准入，未知费用不记零 |
| [社区 PRD](./005-社区互动与内容治理产品需求.md) | 社区内容与处置由社区拥有 | 讨论不默认成为可信知识，不擅自镜像隐藏内容 |

详细接口、来源版本和恢复方法见[知识设计](../design/006-知识库与检索设计.md)。知识、Agent、模型费用同属 assistant 服务内的不同能力，不因分文档增加独立检索微服务；检索引擎和 embedding 选型未因本 PRD 固定。

### 7.4 假设与待决定问题

独立资料的首版格式、大小、正文长度、原件与派生版本保留期限仍需确认。文本／Markdown 和已授权课程图文是现有建议，不是已批准格式清单；PDF、OCR、网页爬取、视频字幕／转写没有自动纳入。真实解析器、检索方案、embedding 模型、质量样本和外部数据处理条件在对应实施任务开始前验证，未有证据时不填写准确率、规模或可用性承诺。

## 8. 版本范围与发布

首版交付 FR-08 的维护、处理、发布、授权检索、引用和撤回闭环。个人知识库与市场留在后续，任意格式解析和视频理解需另行需求；不为这些能力预建系统。

发布前需落实本域输入与保留规则，通过 AC-08、总 PRD 的共同 AC-11／AC-12 以及费用域 AC-17；真实付费调用必须具备相应环境和执行授权。具体任务和证据记录在[知识计划](../plan/007-知识库与检索实施计划.md)及[实施总计划](../plan/002-学习社区与通用Agent实施计划.md)。当前任务全部未开始，没有真实资料导入、模型调用、业务验收或发布结果。
