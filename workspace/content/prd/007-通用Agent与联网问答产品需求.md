## 1. 摘要

让学习者使用不同用途的已发布 Agent，基于当前有权访问的知识库和本次真实联网搜索获得可核对的答案。平台客服与课程助手共用配置机制，首版以有来源、权限正确、失败可理解为成功标准。

最新界面与角色依据为[需求 009](../requirement/009-学屿品牌与界面需求记录.md) UI-S-08／R-28：用户以右下角 Logo 的全局浮层问答，没有独立 Agent 用户页或一级导航；仅管理员配置发布，替代原讲师配置建议。页面与状态见[设计 009](../design/009-学屿首版页面与交互设计.md) G01、P19／P20。

## 3. 背景

用户明确纠正过“两个专用助手”和“业务写入工具”的理解；当前范围是通用配置的 RAG＋联网问答。每答联网与本页失败规则已确认，不能为了降低成本改成按需搜索。现有工程仅有技术基线，没有问答质量或使用效果实证。

## 4. 目标与成功标准

| 目标 | 首版可观察结果 | 验收依据 |
| --- | --- | --- |
| 配置可复用 | 同机制发布至少两个不同用途实例，知识范围可区分，越权绑定被拒 | AC-09 |
| 回答可追溯 | 课程、时效、来源冲突和证据不足问题都有明确处理；每个新答案存在本次真实搜索记录 | AC-10 |
| 故障可解释 | 搜索失败不生成正常答案，重试、零结果、取消和模型未完成可区分 | AC-16；参与总 AC-12 |

这是产品验收目标，尚无准确率、满意度或留存基线，不编造商业改善指标。时间边界是已采纳的处理规则，不是实际可用性承诺。

## 5. 目标用户与细分

首版面向公众学习者中的求助者，以及负责智能服务配置的管理员。学习者只使用可用实例；管理员只绑定获授权知识，受邀讲师角色不授予 Agent 配置权。其余人群不通过增加角色、私人知识库或市场入口进入本版。

## 6. 价值主张

| 维度 | 学习求助者 | Agent 维护者 |
| --- | --- | --- |
| Who | 对课程或平台使用有疑问的学习者 | 配置课程助手、客服等服务的管理员 |
| Why | 获得与自己学习范围相关、可核对依据的解释 | 复用一套机制服务不同知识范围和用途 |
| What before | 尚无访谈；分别使用搜索与问答工具是待验证的现状假设 | 尚无维护成本基线；不宣称已降低人工答疑负担 |
| How | 授权 RAG、本次搜索、分类型引用和明确失败状态 | 角色、知识绑定、允许模型及版本发布／停用 |
| What after | 能判断答案依据及不足，失败时知道如何恢复 | 可以维护不同用途实例而不复制专用产品 |
| Alternatives | 独立搜索、通用问答或人工求助；选择价值仍需试用验证 | 分别维护专用助手或人工FAQ；复用收益需实际验证 |

产品价值假设是把授权资料、当前网页依据和求助入口连在一起；不以生成了文本等同于解决了学习问题。

## 7. 产品方案

### 7.1 主要流程与交互

管理员创建配置 → 绑定授权知识与允许模型 → 显式发布或停用。学习者打开右下角 Logo 全局面板 → 使用当前可用的已发布服务 → 提问并通过权限／费用准入 → 本次检索和搜索 → 生成与来源复核 → 读取完整答案或明确失败，支持取消和主动重试。没有用户 Agent 列表／会话路由，面板开合不能被当作发起或取消业务调用。

面板展示联网阶段、知识／网页来源差异、无证据、未完成、无权和费用不足。现有设计建议先显示阶段与最终完整结果，不新增逐字输出承诺；上游流式处理仍要满足取消和超时规则。Figma 实际证据由设计 009 补齐，不能将界面规划当作交互或业务验收。

### 联网搜索失败策略

| 场景 | MVP 基线行为 |
| --- | --- |
| 新回答与重复请求 | 每个新回答实际发起搜索；同一请求重复提交／查询读取原任务，不重复调用。用户主动重试或重新生成是新尝试，重新搜索；不能用旧答案缓存替代 |
| 超时与重试 | 单次搜索 **8 秒**，最多 **2 次尝试**，证据检索阶段合计 **18 秒**（含并行 RAG、搜索等待与网页读取）；仅网络故障、429、临时 5xx 重试一次。Retry-After 超出剩余时间就失败；不自动切换搜索供应商 |
| 失败停止 | 参数错误、认证／余额问题、安全阻断不重试。两次仍失败或无法形成安全外发查询时，保留问题、提示原因和重试入口，**不调用回答生成模型，不输出正常的纯 RAG 答案**；错误提示不是一次回答 |
| 成功零结果 | 有效搜索返回零相关结果是成功调用。可用授权 RAG 回答并标明“未找到相关网页来源”；两侧均无证据时说明不足，不编造引用。无法解析的响应属于失败，不冒充零结果 |
| 网页读取失败 | 仅引用实际取得的文本／摘要并说明范围；不能凭标题声称读过全文，需要全文才能成立的结论应说明依据不足 |
| 模型失败／取消 | 生成模型自动重试为 **0**，生成总时限 **60 秒**，流式响应空闲时限 **15 秒**；不静默跨提供商切换。超时／断流显示未完成，释放本地运行槽位，保留未知费用预占，用户可主动重试。取消尝试停止上游，不承诺已经发生的调用免费 |
| 次数与成本 | 未完成回答不扣成功问答次数，仍受发起速率和实际费用约束；已发生搜索、embedding、模型费用照实记录。完整的“证据不足”回答计入成功次数 |

搜索只外发处理后的问题／关键词，不发送付费资料原文、身份信息或会话全文；安全处理失败即停止，不以强制联网为由外发。RAG 检索异常也不得静默冒充课程问答，应提示知识服务暂不可用；搜索成功不等于课程依据完整。

### 7.3 跨领域规则与技术约束

| 依赖 | 对方权威与本域责任 | 联合验收 |
| --- | --- | --- |
| [账号 PRD](./002-账号与访问控制产品需求.md) | 可信身份、账号状态；本域校验本人会话，不接受其他用户身份 | 被停用或他人会话不能读取／发起问答 |
| [知识 PRD](./006-知识库与检索产品需求.md) | 已发布有效来源和引用定位；本域只消费当前用户有权证据 | 退款／撤回后生成前、交付前及历史读取复核，不通过另一 Agent 或旧引用绕过 |
| [课程 PRD](./003-课程与媒体学习产品需求.md)与[交易 PRD](./004-交易退款与权益产品需求.md) | 当前内容状态与购买授予；本域不拥有课程权限事实 | 普通停售保留已购知识，成功退款影响相应授予；不得混同两者 |
| [模型费用 PRD](./008-模型接入与AI费用治理产品需求.md) | 允许模型、次数／成本准入和实际用量；本域不得新增隐式模型调用 | 每次新回答先准入；同请求读取不重复调用；未知结果不自动换供应商或抹除费用 |

共享 FR-11／AC-11 的付费保护、FR-12／AC-12 的恢复与运营可见性保留在[总 PRD](./001-学习社区与通用Agent产品需求.md)，本页仅记录问答侧贡献。Agent、知识与费用属于同一 assistant 服务内部模块；具体 API、状态和工程职责引用领域设计，不在 PRD 复制协议或代码。

### 7.4 假设与待决定问题

搜索供应商、真实模型和数据处理条件仍需落实；资料／会话保留期限、引用交互和代表性质量样本尚未确认。阶段＋完整结果展示是当前设计建议，不能因写入本页变成已确认的额外产品要求。首版不增加网页采集系统，摘要不足应如实说明，不能冒充读过全文。

## 8. 版本范围与发布

MVP 包含通用配置、授权 RAG、每答真实搜索、来源、失败及恢复；私人知识库和 Agent 市场后续考虑，自主多 Agent、工作流、任意工具和业务写入不在当前范围。

上线条件为本域 AC-09、AC-10、AC-16 和共享 AC-11／AC-12 通过，并与模型域逐家完成真实 RAG＋搜索验收；配置界面或模拟答案不能证明真实接入。费用准入与核对须在任何实际计费调用前就绪。当前仅文档，全部实施任务未开始，不承诺工期或发布日期。
