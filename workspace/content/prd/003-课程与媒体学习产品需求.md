## 1. 摘要

让受邀讲师维护并提交结构清楚的录播课程，由管理员审核发布，让学员发现课程、按权限播放、保存学习位置并继续学习。首版围绕课程 → 章节 → 课时建立可交付的内容闭环，视频上传规则服务于稳定供课。

## 3. 背景

用户要求视频上传播放和学习，确认课程层级、录播视频和图文、试看、进度和继续学习，普通下架停止新售但已购可继续。后续接受视频输入与恢复推荐作为 MVP 基线。原始材料与确认历史见[课程需求](../requirement/003-课程与媒体学习需求记录.md#2-原始材料与来源)。

当前没有课程业务实现或真实媒体交付证据，也没有播放成功率基线。原拆分时搜索、分类与管理员审核是候选；本轮需求 009 UI-S-06 已确认标题搜索、简单分类和讲师提交管理员审核。完课判定、复杂标签及其他未决定细则不随本轮升级为确认功能。

## 4. 目标与成功标准

讲师能够建立并提交一门课程，经管理员审核后发布，合法媒体可处理并播放，失败能恢复；有权用户能够继续学习，未购买者不能绕过保护。按 AC-02／AC-03／AC-05／AC-14 和总 PRD 的 AC-11／AC-12 验证。本域同时为购买与退款提供真实内容可交付事实；不以首次播放代替首次实际可访问。不虚构完课率、播放性能或容量目标。

## 5. 目标用户与细分

| 用户 | 工作与问题 | 首版边界 |
| --- | --- | --- |
| 管理员／受邀讲师 | 维护课程、组织课时，知道素材何时可以发布 | 维护自身授权范围内内容，上传不等于发布 |
| 学员 | 看目录与试看，获得权限后学习并恢复位置 | 公开注册、不限制职业；付费访问依据交易权益 |
| 内容运营管理员 | 管理可售、可交付与撤回状态 | 普通下架和停止交付分开处理，不能默默损失已购内容 |

## 6. 价值主张

以下替代方式是方案分析，未假称已完成用户研究。

| Who | Why | What before | How | What after | Alternatives |
| --- | --- | --- | --- | --- | --- |
| 讲师 | 可控地发布可学习内容 | 当前只有技术基线，缺少课程与媒体状态 | 结构化编排、上传反馈、显式发布 | 明确何时可交付、失败如何恢复 | 文件分享链接无法表达课程结构和购买权限 |
| 学员 | 连续学习且知道访问限制原因 | 平台尚无目录、播放器与进度闭环 | 课程详情、试看、鉴权播放、继续学习 | 可以从上次位置恢复并获得一致访问结果 | 通用网盘或独立播放器缺少统一学习记录 |
| 运营管理员 | 停止销售时仍履行既有交付 | 销售与内容可用性容易混淆 | 分离下架、撤回与发布版本 | 可解释已购访问及退款起点 | 手工记录内容状态难支撑一致授权 |

## 7. 产品方案

本轮界面确认来源为[需求 009](../requirement/009-学屿品牌与界面需求记录.md) UI-S-05／06、R-25／26，页面映射见[设计 009](../design/009-学屿首版页面与交互设计.md) P03／P04／P06／P07／P12／P13。标题搜索、简单分类和管理员审核由候选改为已确认；原编号保留，业务未实施。

### 7.1 主要流程与交互

| 路径 | 交互与状态 |
| --- | --- |
| 建课与发布 | 草稿 → 编辑课程／章节／课时 → 上传媒体或 Tiptap 图文 → 素材可用 → 讲师提交 → 管理员审核发布；草稿和未发布版本不对学员泄露，退回后可修改再提交 |
| 上传恢复 | 显示上传中、处理中、可用、失败；区分可重试网络问题与须重新导出文件，续传及替换遵循下文基线 |
| 发现与学习 | 浏览目录／详情 → 试看或进入购买 → 获得有效访问权 → 播放／阅读 → 保存位置 → 再次进入继续学习 |
| 下架与撤回 | 普通下架停止新售、保留已购学习；内容撤回独立拒绝交付并联动交易处理，不把内容不可用伪装成退款已完成 |
| 内容替换 | 旧版持续交付，新版处理成功后显式发布；失败不覆盖旧版，旧回调不覆盖当前版本 |

免费学习记录只表达学习关系，不伪造付费购买权益。课程文本可按授权交给知识域，视频不默认自动转写或全部进入知识库。

### 7.2 首版功能、规则与验收

沿用既有 FR／AC 编号；原限定引用 `PRD-ai2workspace-learning-community` 下对应条目经[总览迁移索引](./001-学习社区与通用Agent产品需求.md)定位本页，不重新编号。

| 行为 ID | 关联需求 | 产品行为、规则与适用例外 | 验收 ID 与可观察结果 |
| --- | --- | --- | --- |
| FR-02 | R-02；需求 009 R-25／26 | 课程与学习内容 CRUD、草稿／发布／下架、公开目录与详情、标题搜索和简单分类；讲师提交、管理员审核发布；图文采用规定能力的 Tiptap；已售课程不直接物理删除，具体保留细则仍需落实 | AC-02：草稿及待审版本不公开；管理员审核发布后可浏览、按标题和简单分类发现；退回能修改再提交；未发布修改不泄露；普通下架停止新售且已购仍可学习；特殊撤回按另行确认政策处理 |
| FR-03 | R-03、R-15 | 上传、处理状态、失败恢复；仅可用素材参与发布；鉴权后播放，试看与付费内容明确分开 | AC-03：上传失败可恢复或重传；处理中不可当作已可播放；未购买者不能用媒体地址、文稿接口或引用绕过保护；有权益者能播放；AC-14 验证本页视频上传基线 |
| FR-05 | R-03 | 我的课程、最近学习位置和进度；暂停／离开后可继续；学习进度不授予购买权益；完课判定为未确认候选 | AC-05：同一用户再次进入可恢复位置；用户间进度隔离；课程内容变更时说明进度兼容结果；完课判定纳入范围后再按评审标准验证 |

| 补充验收 ID | 可观察结果 |
| --- | --- |
| AC-14 | 合法边界可上传；超大小／时长／分辨率／帧率、伪 MP4 和损坏文件被拒；有效期内续传，过期重传；重复完成通知只创建一个处理版本，失败替换不影响旧版 |

### 视频上传规格

| 项目 | MVP 基线规则 |
| --- | --- |
| 允许输入 | MP4 容器、H.264 视频、8-bit SDR；音轨可缺省，有音轨时为 AAC。首版不接受 HEVC、HDR、4K、ZIP 批量包或其他容器；不合格时明确提示重新导出 |
| 单文件边界 | 大小大于 0 且 **≤2 GiB（2,147,483,648 字节）**；时长大于 0 且 **≤120 分钟**；旋转后画面长边 ≤1920、短边 ≤1080；帧率 ≤30 fps，各项均需满足。横竖屏均可，建议按 10～30 分钟拆课时 |
| 上传恢复 | 每位讲师最多 **2 个并行上传会话**；采用存储官方分片／续传能力直传。会话自创建起保留 **24 小时**，续传须重新鉴权；过期重传，失效分片最终清理，不永久占空间 |
| 服务端校验 | 前置核验声明大小；完成后核验实际大小、容器、编码、时长、分辨率、帧率和可解码性。伪装扩展名、损坏或超限文件不得发布；错误区分网络可重试和文件需重新导出 |
| 播放产物 | 受保护 HLS，H.264／AAC，最多 **720p、1080p 两档**，保持比例且不增加帧率；不足对应档位不升采样，低于 720p 保留源分辨率单档。首版不提供学员原片下载入口 |
| 版本替换 | 新文件是新版本，处理成功后显式发布切换；处理失败不覆盖仍在使用的旧版。因违规撤回旧版独立处理，不通过回退重新公开违规内容 |

这些是已采纳的产品输入门槛，不是云厂商通用上限；首版不建设通用视频编辑或格式转换平台。图文附件、字幕与转写不因本次规格自动纳入实施。

### 7.3 技术约束、失败与跨领域关联

媒体采用受保护访问，源文件与播放产物不能因公开链接绕过业务鉴权；鉴权范围覆盖 HLS 所需资源，不只检查播放器页面。具体上传、版本和交付设计见[课程设计](../design/003-课程与媒体学习设计.md)。撤权后新授权请求按当前权益拒绝；已签发短期凭据存在残留窗口，已缓冲内容也不承诺能即时回收，实际媒体失效窗口须在上线验收明确。

| 边界／依赖 | 对方责任与本域责任 | 联合验收贡献 |
| --- | --- | --- |
| [账号](./002-账号与访问控制产品需求.md) | 提供当前主体与资格；本域判断课程归属 | 普通用户不能供课，讲师不能改他人课程 |
| [交易](./004-交易退款与权益产品需求.md) | 交易拥有价格、订单和购买权益；本域提供可售／可交付事实及历史 | 支付后可交付时才形成实际访问；延迟交付不缩短退款窗口；退款后拒绝新的付费播放 |
| [社区](./005-社区互动与内容治理产品需求.md) | 消费当前课程访问判断；本域不将“曾学过”作为永久授权 | 已失权用户不能继续读写受保护课程讨论 |
| [知识](./006-知识库与检索产品需求.md) | 消费授权内容、来源与版本；本域提供撤回事实 | 文稿与引用不能绕过课程权，撤回资料不因索引尚在而继续泄露 |
| 上传／媒体失败 | 显示实际失败及恢复入口，不假称可发布；重复回调幂等 | 处理失败不破坏旧版，非法文件不可发布 |
| 内容与进度变化 | 进度按本人和课时隔离，旧上报不能错误覆盖新状态 | 拖动位置不自动认定完课；版本兼容规则在评审后验证 |

FR-11／FR-12、AC-11／AC-12 的共同正文保留于[总 PRD](./001-学习社区与通用Agent产品需求.md)。本域贡献是媒体、文稿和交付状态授权及可恢复上传，不重复定义共享规则。

## 8. 版本范围与发布

首版为结构化录播与图文课程、上传与保护播放、试看和继续学习。直播、考试作业、证书、通用视频编辑、学员原片下载及自动转写不随本次拆分进入 MVP；未确认候选继续保留评审入口。

[课程实施计划](../plan/004-课程与媒体学习实施计划.md)划分前端编排／上传／播放器与后端内容版本／处理／鉴权／进度任务，并依赖账号、交易权益和媒体能力。发布前须通过 AC-02／AC-03／AC-05／AC-14、有关 AC-11／AC-12、真实上传播放及受保护资源拒绝验收。当前全部业务与供应商验收未开始；本文不代表实施或发布授权。
