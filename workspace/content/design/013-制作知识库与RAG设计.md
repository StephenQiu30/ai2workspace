## 职责与页面

制作知识库负责授权入库、检索、引用和版本记录。制作工作台侧栏提供检索输入、所属 IP、结果片段、来源版本和打开原文。IP 专页及二创项目可以显示允许公开或允许用于二创的检索视图。内部入库、处理失败与撤回在设定与素材页管理，避免新增独立用户端入口。

| 输入或执行环节 | 设计 |
| --- | --- |
| 知识来源 | 由制作域提供正式角色、世界观、时间线和已确认的剧本或前集文本。首版用文本和结构化设定字段做验证 |
| 派生索引 | assistant 域可复用已有知识处理结构，索引条目保留工作区、IP、作品、来源类型和版本。制作域仍拥有源事实 |
| 请求上下文 | 从当前会话与项目派生工作区及用途，按制作内部、公开浏览或二创校验同一来源的可见性。检索前过滤，返回及打开引用时再核验 |
| 检索结果 | 返回片段、来源、版本和定位。对相关资料缺失、来源冲突、失败、无访问权使用相应状态 |

已核对仓库存在知识来源、处理任务和验证代码，制作上下文及授权目的需新增。[既有知识库与检索设计](./006-知识库与检索设计.md)

## 同步与恢复

D-01 正式设定审批或素材开放变动后，索引处理按来源 ID 和版本幂等更新。处理中展示待可用状态。发布使用索引已就绪且仍获授权的版本，失败可重试并保留原版本标识。

D-02 版本追溯与当前权限并行，运行保存命中版本，用户重新打开时再次检查资格。撤回先改变源状态，旧索引、缓存和历史结果后续按当前权限过滤。历史生成内容包含已失权资料的原文或转述时，隐去相应内容或限制整条详情，在适用权限内保留运行状态和审计记录。权限范围的规则见[原创IP设定与素材](../design/011-原创IP设定与素材设计.md)。

制作检索优先用项目资料。代表性查询验证角色别名、时间线事实、跨集引用和缺证据。是否支持语义检索及外部参考，依据样本质量和获准数据范围评审。制作 Agent 消费方式见[制作Agent与任务编排](../design/014-制作Agent与任务编排设计.md)。

## 非功能设计与验证

| 需求 | 设计措施与验证方法 | PRD 验收 |
| --- | --- | --- |
| NFR-01 | 结合工作区、用途与当前权限过滤，并在送入模型前再次检查；撤回时按来源版本隔离旧缓存与历史视图 | AC-11 |
| NFR-02 | 索引和源状态分别维护；只从已就绪且允许的版本返回。失败重试使用相同来源版本标识 | AC-12 |
| NFR-03 | 固定样本、期望来源和版本，记录候选命中和阶段耗时；用一套条件对照变更前后记录 | AC-13 |

## 验证映射

| 需求／验收 | 验证方法 |
| --- | --- |
| R-01／AC-01 | 用制作账号和二创账号查询同一角色，确认结果与用途一致且引用能定位 |
| R-02／AC-02 | 用不同版本及冲突资料验证来源追溯，模拟无结果和索引异常并核对状态 |
| R-03／AC-03 | 保留旧索引及历史记录后撤回资料，验证新检索、旧引用与下游运行权限 |

评测样本、切片参数和允许发给模型的资料范围待确认，执行结果待记录。
