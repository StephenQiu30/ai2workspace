## 1. 背景、范围与非目标

工程当前没有课程、上传、存储、播放或学习记录。首版交付课程 → 章节 → 课时的录播与图文学习流程，由管理员和受邀讲师供课，支持免费课、试看及付费课程的受控访问。

本领域维护课程内容与归属、版本、发布和停止交付事实、媒体与处理任务、学习记录。交易金额、订单、退款和购买授予由 commerce 管理；社区内容由 community 管理；业务知识库索引与 Agent 由 assistant 管理。

视频规格只引用 [PRD 视频上传规格](../prd/003-课程与媒体学习产品需求.md#视频上传规格)这一数值来源。首版不包括直播、通用视频剪辑、任意格式转换、学员原片下载、考试证书；字幕／转写与附件下载政策未确认，不因为上传视频而宣称能检索视频全部内容。

## 3. 内容、上传与学习流程

### 课程状态和版本

课程身份、可编辑草稿和已发布版本分开。编辑草稿不修改学员当前看到的内容；审核通过后原子切换发布版本，章节／课时引用同时对应该版本。标题、简介、课时与媒体引用的删除或调整需基于预期版本，过期编辑返回冲突。

| 维度 | 状态及意义 | 转换约束 |
| --- | --- | --- |
| 内容制作 | 草稿、待审核、已通过／驳回 | 提交前校验必要内容和素材；讲师不能自行绕过既定审核流程 |
| 销售 | 可售、停止新售 | 停售不撤销已购访问；实际售价在 commerce |
| 内容交付 | 可交付、暂不可用、已撤回 | 撤回独立于停售；原因、操作者、有效时间和内容版本可追踪 |
| 发布引用 | 当前发布版本、历史版本 | 切换必须指向已通过且素材可用版本；不得回退到已撤回内容 |

未售草稿可以删除；已有订单关联的课程保留稳定 ID、购买快照所需引用和状态记录，不能通过通用 CRUD 物理抹除历史。永久停止交付后的商业处理引用 [PRD 退款规则](../prd/004-交易退款与权益产品需求.md#退款规则)，learning 提供事实，不自行标记退款成功。

公开目录与详情只读已发布且允许公开的字段；试看明确定位到允许的课时或内容片段。[需求 009](../requirement/009-学屿品牌与界面需求记录.md) UI-S-05／06 已确认介绍、价格和目录公开，以及标题搜索、简单分类、讲师提交管理员审核发布；学习正文和媒体仍按当前课程权限读取，其他未确认字段不默认公开。

### 上传会话与处理

1. 服务端检查讲师资格、课程归属、目标课时、声明规格和并行上传会话额度，创建带有效期的会话及短期上传授权。
2. 浏览器通过供应商官方分片／续传能力直传；续传、刷新凭据和完成操作均重新校验会话归属，不授予整个存储空间写入权。
3. 完成后服务端核验实际对象大小、容器、编码、时长、旋转后画面、帧率及可解码性，不能只信 MIME／扩展名／浏览器上报。
4. 校验通过后对源版本建立唯一处理任务，先输出临时产物，再确认完整 HLS 产物可用后标记 ready；仍需显式发布切换。
5. 重复完成、重复供应商通知和 Worker 租约恢复不重复创建有效版本；新版本失败保留旧的正常发布版本。

| 对象 | 状态 | 恢复边界 |
| --- | --- | --- |
| UploadSession | 待上传、上传中、已完成、已取消、已过期 | 网络故障可续传；过期重新申请；结束后释放并行会话占位 |
| SourceVersion | 待校验、校验失败、已校验 | 不合格源文件需重新导出，不无限猜测格式 |
| MediaJob | 待处理、处理中、可用、失败 | 明确失败原因；供给者有权限重试；旧任务不得覆盖新版本 |
| PublishedMedia | 当前可用、已替换、已撤回 | 回退只允许仍合法有效的版本；撤回不能被重试自动恢复 |

取消／过期主动终止未完成分片，并通过周期清理补偿；清理前核对完成竞态，已发布源文件和有效播放产物不套用“过期分片”删除规则。供应商回调验证签名、账户与资源映射，不因收到 ready 字样就发布课程。

### 受控播放与进度

播放前检查账号、当前内容状态、试看范围与 commerce 权益。保护覆盖 HLS 清单、片段、密钥及受限图文，不能仅保护课程页面。短期播放凭据限制资源和用途，不提供永久公开原片地址。

凭据到期需重新授权；退款、账号停用或内容撤回后，新授权应拒绝。已签发凭据与缓冲片段可能存在残留窗口，其上限和供应商能力必须在上线门禁验证，不能承诺远程收回已交付字节。

学习记录按用户、课时和内容版本保存最近位置、更新时间及更新版本；采用条件更新避免旧设备迟到写覆盖新状态，冲突时返回权威版本供前端处理。当前先做继续学习，不用“最大播放位置”推导完课；多设备优先规则与完课阈值未确认。

免费课的加入只登记学习关系，不创建付费购买授予；“我的课程”组合学习关系与当前购买权益，通过领域 API 获取，不跨库联表。失去访问权时保留必要进度但不暴露受限课程正文。

## 4. HTTP、数据权威与跨服务契约

公共路径前缀为 `/api/learning/v1`。下表是本轮契约设计，实际 DTO／标签／Swaggo 注释在所属 Go 包维护；稳定 operationId 生成对应客户端。公共身份来自 identity，用户不得指定他人身份上报进度或申请播放。

| operationId／方法与路径 | 输入 → 输出 | 权限及主要错误 |
| --- | --- | --- |
| `learningListCourses` GET `/courses`；`learningGetCourse` GET `/courses/{id}` | 分页或 courseId → 允许公开／当前授权的课程视图 | 不泄漏草稿；不存在或不可见 404 |
| `learningCreateCourse` POST `/courses`；`learningUpdateCourse` PATCH `/courses/{id}` | 内容、expectedVersion → 草稿及版本 | 管理员／归属讲师；角色不足 403，冲突 409 |
| `learningDeleteCourse` DELETE `/courses/{id}` | expectedVersion → 删除／归档结果 | 已售关联不能直接物理删除；不符合条件 409 |
| `learningSubmitCourse` POST `/courses/{id}/submissions`；`learningReviewCourse` POST `/courses/{id}/reviews` | 版本、动作与意见 → 审核／发布状态 | 提交者有维护权，审核者有管理权；素材未就绪 409 |
| `learningCloseSales` POST `/courses/{id}/sales-closure`；`learningWithdrawCourse` POST `/courses/{id}/withdrawals` | 版本、原因 → 销售／交付状态 | 撤回为管理员处置；停售不能等价撤权 |
| `learningCreateUpload` POST `/lessons/{id}/uploads` | 文件声明、幂等键 → uploadId、sourceVersion、expiresAt、uploadInstructions | 维护权、上传额度与规格；超限 413／429 |
| `learningCompleteUpload` POST `/uploads/{id}/completion` | 分片／对象完成信息、幂等键 → sourceVersion、处理状态 | 校验实际对象；已过期 410；同键不同输入 409 |
| `learningGetUpload` GET `/uploads/{id}`；`learningCancelUpload` DELETE `/uploads/{id}` | uploadId → 状态／取消结果 | 会话归属；取消完成竞态不误删有效素材 |
| `learningRetryMediaJob` POST `/media-jobs/{id}/retries` | 失败任务及预期版本 → 当前处理任务 | 仅可恢复失败；旧源／已撤回不得重发为有效内容 |
| `learningAuthorizePlayback` POST `/lessons/{id}/playback-authorizations` | 访问用途 → 限资源播放信息与到期 | 当前授权；未购 403；媒体未就绪 409；依赖异常 503 |
| `learningSaveProgress` PUT `/lessons/{id}/progress`；`learningGetProgress` GET 同路径 | contentVersion、position、expectedVersion → 权威进度 | 仅当前用户；超出时长等输入 400；过期更新 409 |
| `learningJoinFreeCourse` POST `/courses/{id}/enrollments`；`learningListMyCourses` GET `/me/courses` | 免费课 ID 或分页 → 学习关系／本人课程摘要 | 已验证账号；付费课不能用加入接口获取权益 |

章节／课时 CRUD 和排序是课程草稿的一部分，按对象维护权与 expectedVersion 更新；图文读取沿当前发布与访问检查，不从无鉴权静态路径绕过。

### 内部 HTTP 契约

| operationId／路径 | 输入 → 输出 | 使用者与约束 |
| --- | --- | --- |
| `learningGetSaleSnapshot` GET `/internal/learning/v1/courses/{courseId}/sale-snapshot` | courseId → courseId、title、publishedVersion、saleState、deliverable | commerce 下单查询；不查购买权益，防止递归 |
| `learningCheckCourseAccess` POST `/internal/learning/v1/course-access/check` | 可信 userId、courseId、purpose → allowed、reason、accessVersion、contentVersion | community／assistant 使用；purpose 包含 playback、discussion、knowledge；综合内容状态和权益 |
| `learningGetKnowledgeSource` GET `/internal/learning/v1/courses/{courseId}/knowledge-sources?version=…` | 已认证维护 actor、版本 → sourceId、sourceVersion、contentVersion、授权图文与权限引用 | assistant 入库；不返回未授权讨论，不自动包含视频转写；使用者权限另行检查 |
| `learningGetDeliveryEvidence` GET `/internal/learning/v1/courses/{courseId}/delivery-evidence?notBefore=…` | commerce 的 grantActivatedAt → firstDeliverableAt 或未交付、evidenceVersion、contentVersion | 从可交付状态记录获得首次可用证据；不依赖浏览器播放，也不因通知迟到重置 |
| `learningCheckCourseManagement` POST `/internal/learning/v1/course-management/check` | 可信 actor、courseId、purpose → allowed、resourceVersion | commerce 设置价格、assistant 绑定来源前验证维护权 |

内部路由仅授权服务可调用，检查服务身份及被允许用途，不能把浏览器提交的 userId 直接透传为可信主体。`learningCheckCourseAccess` 调用 `commerceCheckEntitlement` 获取付费授予；免费／试看按本域规则判断。commerce 的下单快照查询不反查权益，避免一次请求在两个服务之间循环。

授权查询失败时拒绝受保护内容，不能使用无限有效的正向缓存。来源导入、当前学员访问与内容可交付是不同判断；assistant 必须再按当前用户核验，不能继承维护者的读取权限。

### 数据及事件

| 数据权威 | 字段与约束 | 跨域行为 |
| --- | --- | --- |
| Course／ContentVersion | 课程归属、草稿版本、发布引用、章节课时、销售／交付状态 | 价格与订单不在此重复维护 |
| Upload／MediaVersion／Job | 资源归属、官方上传引用、源和输出版本、状态、租约、重试记录 | 供应商 ID 是外部引用，不能替代本域授权 |
| Progress／Enrollment | userId、lessonId、contentVersion、position、更新版本 | 保留学习关系不代表有付费访问权 |
| DeliveryEvidence | 交付状态变更的有效时间、内容版本与证据版本 | commerce 据此计算退款窗口起点，保留历史事实 |
| PendingDelivery | eventId、事件类型、对象版本、最小摘要 | 与业务更新同事务保存；投递 commerce／community／assistant，接收方去重 |

课程可交付状态变化需可靠通知 commerce；课程撤回先改变权威状态，索引清理和通知随后补偿。通知包含对象引用及必要状态，不携带付费课文；通知失败不回滚已经发布或撤回的状态。

## 5. 设计决定与取舍

| 决定 ID | 选择及依据 | 影响与风险 |
| --- | --- | --- |
| D-01 | 内容发布、停止新售和停止交付分开 | AC-02、AC-11；普通下架不会误伤已购访问 |
| D-02 | 官方直传／续传，域内处理任务与版本发布 | AC-03、AC-14；真实供应商规格与清理行为需验证 |
| D-03 | learning 统一组合内容状态与 commerce 权益 | 防止社区／Agent 只看购买而绕过内容撤回；授权依赖不可用时拒绝 |
| D-04 | 用服务端交付事实支持退款起算 | AC-15；避免首次播放、通知到达或重试时间替代实际可用时间 |
| D-05 | 继续学习先保存版本化位置，完课另议 | AC-05；不引入未经确认的观看率统计／退款扣费 |

## 6. 实施、发布与恢复

任务与依赖见[领域计划](../plan/004-课程与媒体学习实施计划.md)。先闭合课程内容和内部契约，再上传处理，最后付费播放／继续学习；前端可用约定契约并行开发，真正付费播放需 commerce 已交付权益能力。

真实媒体验收前落实存储／转码／CDN、服务回调、允许的输入和完整 HLS 鉴权。身份、生成链路和共享配置由总计划衔接；不为尚未确定的供应商创建适配空壳。

处理故障保留源版本、失败原因和可恢复任务；新版本失败不切换发布引用。回滚镜像不能恢复被撤回内容；课程、任务与媒体对象的一致恢复需演练，派生媒体可重建但已删除原片不能假定可恢复。
