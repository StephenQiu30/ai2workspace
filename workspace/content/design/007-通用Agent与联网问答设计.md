## 1. 目标与边界

通用 Agent 通过角色说明、授权知识库集合和所配置模型服务不同场景。平台客服和课程助手是实例，课程不是 Agent 的必填单一归属。按[需求 009](../requirement/009-学屿品牌与界面需求记录.md) UI-S-08／R-28 的最新纠正，**仅管理员配置发布**，学员通过右下角 Logo 打开的全局面板使用可用实例；受邀讲师不再具有 Agent 配置权。用户独立 Agent 页面和一级导航被本轮替代，详见[页面设计 009](./009-学屿首版页面与交互设计.md) G01、P19／P20。

首版是有限的 **授权 RAG＋每答真实联网搜索＋生成回答** 流程。不建设可视化工作流、多 Agent 编排、任意工具运行器，不执行退款、发帖、改课程等业务写入。用户早期对写入的选择已经被后续 RAG＋联网纠正替代，不能重新纳入。

本域拥有 Agent 发布版本、会话、问答运行状态和来源展示；不拥有课程权限、知识原文或供应商价格。搜索和模型失败遵循 [PRD 联网搜索失败策略](../prd/007-通用Agent与联网问答产品需求.md#联网搜索失败策略)，费用遵循对应预算设计，不能通过更换 Agent 绕过限制。

## 3. 配置与问答流程

### 配置发布

Agent 状态为 `draft → published → disabled`，仅管理员编辑产生新草稿版本，发布时检查管理员资格、所有知识库绑定的来源授权和模型是否启用。每次回答固定使用准入时的发布版本；发布新版不修改已经发生的调用记录。停用立即拒绝新问答，现有问答在外发资料和返回前复核，不因旧配置快照继续越权。

不提供“关闭联网仍正常回答”的设置。角色说明只能影响语气和任务领域，不能扩展资料权限、预算、供应商或工具。模型变更要显式发布新版本，并显示相应的数据处理和费用影响，不在运行中悄悄切换。

### 一次新回答

1. 验证账号、会话归属、Agent 可用性和问题合法性；对幂等键查询原运行，相同键不同内容拒绝冲突。
2. 以确定性规则生成可外发问题／关键词，不含付费资料原文、身份信息或整段会话；无法安全形成查询时返回明确阻断，不跳过搜索。
3. 调用 `usage.Reserve` 原子检查成功次数占位、发起速率、并发和预算；预占不成功时不产生任何付费外部调用。
4. 在统一证据截止时间内执行 `knowledge.Retrieve` 与实际搜索。两者可并行，权限过滤必须先于受保护证据使用；搜索计费尝试必须逐次记录。
5. 只有有效搜索成功且必需知识检索未失败，才整理证据和引用。搜索零相关结果可成立，无依据时明确证据不足；不把服务错误改写为零结果。
6. 重新检查受保护来源状态，按配置调用一次模型；输入裁减受预算约束且保持来源关联，不暗中追加改写问题或反思调用。
7. 获得完整生成结果后，复核权限、来源与引用，持久化答案和来源关系，再向前端交付；成功次数只消耗一次，费用按实际用量或未知状态独立结算。

首版建议前端显示检索／搜索／生成阶段，取得最终完整答案后展示正文。可以消费上游流式响应以实现取消、空闲超时和用量记录，但不额外承诺逐字输出交互；浏览器暂断可通过同一 runId 恢复状态。这样完成前的权限复核有明确边界，避免流中拼接重试答案。该交互属于设计选择，不改变 PRD 对上游流式或已声明完整返回的验收要求。

上述问答均在 G01 全局面板承载，顶部没有 Agent 导航。收起面板不触发取消或新调用，再次打开查询同一 runId；取消为显式动作。游客／未验证账号的面板入口只提供认证指引，真正发起仍遵循本人、邮箱与费用准入。不同用途的上下文选择属于面板设计，不新增独立用户路由或让页面上下文绕过资料授权。

## 4. 状态、失败与用户反馈

问答运行状态为 `admitted → retrieving → generating → completed`，可在中间终结为 `failed / cancelled`。本地运行状态、答案完成状态、费用结算状态分开保存。没有完成的答案不能显示成功或扣成功次数；已产生的成本仍然存在。

| 情形 | 产品表现与后端行为 | 验证边界 |
| --- | --- | --- |
| 搜索瞬时故障 | 单次最多 8 秒，最多两次；网络、429、临时 5xx 才可重试 | 证据阶段合计 18 秒；Retry-After 超出余量直接失败，不切搜索供应商 |
| 搜索认证／参数／余额或安全错误 | 保留问题，显示可理解原因，停止正常作答 | 不重试，不调用生成模型，不输出纯 RAG 正常答案 |
| 成功零结果 | 显示“未找到相关网页来源”，依据授权知识回答或说明证据不足 | 有效响应零结果与解析失败不同；不能伪造网页链接 |
| 知识服务异常 | 显示知识暂不可用并保留重试入口 | 不用网页回答冒充完整课程依据；确实无授权知识与服务异常分开 |
| 网页全文不可得 | 引用已取得摘要或片段并标明范围 | 不声称已读全文；首版不建设额外网页爬取系统 |
| 模型超时／断流 | 生成总时限 60 秒、流空闲 15 秒；明确未完成 | 自动模型重试为 0，不切提供商；释放本地运行槽，未知成本仍预占 |
| 用户取消 | 本地终态并向在途调用传递取消 | 取消不等于上游未计费；取消与完成竞态只能有一个用户结果终态 |
| 重复提交／主动重试 | 同 requestId 返回原运行；主动重试生成新 requestId 并重新准入和搜索 | 原记录查询不再次产生模型费用或成功次数；历史内容返回前复核当前权限 |

网页／知识内容都作为不可信数据，不能覆盖系统权限与工具限制。外部查询只能由应用构造，不直接执行模型生成命令；若后续增加网页全文读取，应先验证公网协议、目标和重定向，防止访问内网，并纳入既有证据时限。

## 5. 接口、数据与一致性

公共前缀 `/api/assistant/v1`；仅描述计划契约，不手工创建 Swagger 或生成客户端副本。

| HTTP / operationId | 关键输入 → 输出 | 权限与错误 |
| --- | --- | --- |
| `POST /agents` / `createAgent` | `{name, roleInstruction, knowledgeBaseIds, providerId, modelId}` → `{agentId, draftVersion}` | 仅管理员，只绑定获授权来源；讲师角色不能取得配置权 |
| `PATCH /agents/{agentId}` / `updateAgent` | `{expectedVersion, configuration}` → `{draftVersion}` | 仅管理员；版本冲突拒绝，不能配置业务写入或绕过联网 |
| `POST /agents/{agentId}/publish` / `publishAgent` | `{draftVersion}` → `{publishedVersion, state}` | 仅管理员；验证知识绑定、模型允许清单和配置完整性 |
| `POST /agents/{agentId}/disable` / `disableAgent` | `{expectedVersion, reason}` → `{state}` | 仅管理员；拒绝新运行并影响在途交付复核 |
| `GET /agents`、`GET /agents/{agentId}` / `listAgents`、`getAgent` | 可见范围／ID → 可使用实例或授权管理信息 | 学员不获得内部提示词、密钥或无权知识配置 |
| `POST /agents/{agentId}/answers` / `startAnswer` | `{conversationId?, question, requestId}` → `202 {runId, conversationId, state}` | 已验证用户、会话本人；请求准入失败明确返回限额／配置／权限原因 |
| `GET /answers/{runId}` / `getAnswer` | runId → `{state, phase, answer?, citations?, errorCode?}` | 本人；返回正文／引用前复核当前来源权限，受限内容整体隐藏而非残留在摘要 |
| `POST /answers/{runId}/cancel` / `cancelAnswer` | runId → `{state}` | 本人；终态幂等，不能取消他人的运行 |
| `GET /conversations/{id}` / `getConversation` | conversationId → 可访问消息及受限占位 | 会话归属＋消息来源权限；退款后历史消息不继续泄漏付费内容 |

内部 `agent.StartAnswer(ctx, AnswerInput) (AnswerRun, error)` 中 AnswerInput 为可信用户、agentId、conversationId、question、requestId；AnswerRun 含 runId、状态和配置版本。`knowledge.Retrieve` 与 `usage.Reserve / Reconcile` 的具体入出遵循相应领域设计，不重复创建第二套权限／计费接口。

AgentVersion 保存发布快照和所绑定知识库；Conversation 保存所属用户；AnswerRun 保存请求哈希、配置版本、检索／搜索记录、引用和终态；SearchAttempt 保存尝试序号、提供商请求 ID、结果类型、时间及成本关联。搜索日志不保留付费原文或完整会话。答案引用区分 `knowledge` 与 `web`；网页记录真实 URL、标题、获取时间及摘要／全文范围，知识记录来源版本和定位。

相同 `(userId, requestId)` 唯一；持久化完整答案与成功次数结算使用本服务事务协调，不能因客户端未收到响应重复计次。在途进程退出后根据持久状态恢复查询和费用核对；不自动重发结果未知的模型调用。错误提示不暴露上游 Key、内部地址或敏感资料。

## 6. 设计决定与外部依据

本页 D-ID 归属 `DES-ai2workspace-agent`。

| ID | 选择及依据 | 影响 |
| --- | --- | --- |
| D-01 | 一套配置与发布机制服务客服、课程等场景 | 不为实例建立新服务，知识和能力由显式绑定约束 |
| D-02 | 应用层强制搜索，而非提示模型自行选择工具 | 每个新答案具有可核对的搜索尝试；搜索故障会阻断 AI 作答 |
| D-03 | 有限流程及完整结果交付，幂等读取恢复 | 避免自主循环及断流自动重发；逐字交互可在后续明确需求后评估 |
| D-04 | 失败停止而非纯 RAG／跨供应商静默降级 | 保留用户每答联网与外发边界，学习播放不依赖 Agent 正常运行 |
| D-05 | 按需求 009 UI-S-08 改为用户端全局 Logo 浮层，管理员配置 | 替代原独立用户页面与讲师配置权限；API 资源名、每答联网与费用规则不因界面改动而重定义 |

沿用前轮 2026-11-17 已核验的 [OWASP 提示注入防护说明](https://cheatsheetseries.owasp.org/cheatsheets/LLM_Prompt_Injection_Prevention_Cheat_Sheet.html#agent-specific-defenses)，支持将检索材料当作数据、将权限与工具控制留在应用侧。本轮只整理设计，没有重新查验外部资料或调用模型。

## 7. 实施、恢复与验收

配置 CRUD 可以在身份／知识契约明确后先开发；任何真实索引、搜索或生成都必须等待统一费用准入和供应商配置验证。上线前每家模型都需完成实际 RAG＋搜索闭环，不能拿一种模型的结果替其他三家签收。

| 验收 | 独立可观察条件 | 记录位置 |
| --- | --- | --- |
| AC-09 | 两种用途实例复用机制；学员／讲师配置拒绝；管理员越权绑定拒绝，停用拒绝新问答 | [领域计划](../plan/008-通用Agent与联网问答实施计划.md) |
| AC-10、AC-16 | G01 原页面打开／收起／恢复同一运行；每次新答案真实搜索；超时／认证／零结果区分；失败无生成；重试有新记录 | 同上；界面状态见设计 009 |
| AC-11 | 已退款／撤回／停用后无法通过另一 Agent、历史结果或引用读取受限资料 | 同上及知识领域验收 |
| AC-12 | 中断后状态可恢复；未知模型结果不自动重新发送；课程仍可学习 | 同上 |
| AC-13 | 四个提供商分别验证真实配置、用量与来源，不静默切换 | [模型与费用计划](../plan/009-模型接入与AI费用治理实施计划.md) |

搜索提供商、实际模型、引用展示细节、会话与请求数据保留期限及数据外发条件仍需实施前落实。当前完成的是设计拆分；没有业务实现、真实供应商验收、部署或付费调用。
