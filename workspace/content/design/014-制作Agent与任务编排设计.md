## 作品内运行入口

在剧本、分镜和审片视图内使用 **生成草稿**、**转为分镜**、**检查一致性**。任务抽屉显示运行、步骤、结果预览、来源版本、耗时、用量及失败。操作者按字段比较或采纳候选结果。审核人员从作品版本记录查询对应运行。

## 固定制作流程

| 步骤 | 输入 | 输出与权限 |
| --- | --- | --- |
| 编剧 Agent | 创作简报、当前允许使用的角色和设定 | 可编辑的分场与对白候选。制作人员采纳后形成剧本草稿 |
| 分镜 Agent | 人工选定的剧本版本、设定和素材引用 | 场到镜头映射、景别、时长与素材需求候选。逐镜编辑确认后用于制作 |
| 校验 Agent | 指定的剧本、分镜或待审镜头版本及引用 | 按位置列出人物、道具与时间线冲突，标出依据或证据不足。审片人员决定是修正还是记录例外 |
| 媒体任务 | 已确认镜头的生成或合成参数 | 可选择的媒体产物、运行状态、成本记录。候选采用及定稿仍走制作页 |

D-01 使用带人工确认点的固定流程。知识检索和步骤路由由任务流程处理，Agent 输出写入候选区，制作人员确认后才改变项目版本。发布、开权、退款由各业务域的人工入口和服务规则处理。检索的上下文与引用契约见[制作知识库与RAG](../design/013-制作知识库与RAG设计.md)。

## 职责、恢复与费用

制作父 Agent 按固定流程分派子 Agent，由各子 Agent 按任务用途使用 RAG。运行记录展示父子关系、来源和用量。交付前用 Evals 验证编排、检索和候选质量。代码归属、恢复和评测数据见[Agent 模块组织与执行设计](./020-Agent模块组织与执行设计.md)。

制作域持有正式与草稿版本。单体的 `agent/application/agent` 负责 Agent 运行、步骤和候选结果，复用助手模块的模型适配和费用准入；用量仍由助手模块记录。渲染执行归 `creation`，并关联可收费步骤。制作任务模型、媒体工具和编排随对应业务实现。[既有Agent设计](./007-通用Agent与联网问答设计.md) · [费用治理设计](./008-模型接入与AI费用治理设计.md)

D-02 每次运行记录任务、输入版本、配置版本、引用和步骤。重复提交返回同一运行，已成功步骤保留。重试前先确认原任务和账务状态，用户可以在原失败步骤继续，或用新版本新建运行。取消保留当时状态和已发生用量；上游迟到结果进入候选或核对区，不能覆盖之后已选定的版本。

D-03 付费任务须先预算准入。额度不足时显示受限，操作者可继续手工编辑。结果或用量未知时保留核对记录，按运营确认处理。供应商、预算与具体失败阈值评审后填写。

## 非功能设计与验证

| 需求 | 设计措施与验证方法 | PRD 验收 |
| --- | --- | --- |
| NFR-01 | 按固定步骤校验输入和输出结构，执行工具名单与权限独立于模型文本；拒绝候选指令导致的状态变更 | AC-11 |
| NFR-02 | 先预占预算，使用运行与步骤标识关联外部请求。未知结果进核对，不以本地重试代替确认 | AC-12 |
| NFR-03 | 用运行与步骤标识串接版本与用量，记录可共享摘要与受限原文；按权限读取运行详情 | AC-13 |
