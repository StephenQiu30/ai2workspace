## 1. 目标、范围与非目标

首版至少支持 DeepSeek、OpenRouter、火山、OpenAI，每家选择经过验证的实际模型。支持提供商不等于兼容该品牌全部模型、端点、推理参数或原生工具。具体模型、区域、账号及价格仍待选型与真实验收。

本域使问答和知识入库在可知费用上界内准入，并区分成功次数、实际成本与待核对费用。平台承担有限 AI 成本，不建立钱包、用户充值、积分、自动超额收费、BYOK 或模型市场；支付课程订单仍归 commerce，AI 使用不会从课程退款中扣费。

全部产品数值以 [PRD AI 费用控制](../prd/008-模型接入与AI费用治理产品需求.md#ai-费用控制)为唯一来源；下文只说明如何落实，不复制第二份完整配置表。原子预算控制必须早于第一个可能付费的索引、查询 embedding、搜索或生成调用。

### 四家逐一适配

| 提供商 | 必须记录与核验 | 不可作出的假设 |
| --- | --- | --- |
| DeepSeek | 实际端点与模型、输入／缓存／输出／推理用量、停止原因和错误 | 协议相似不代表所有模型支持同一流式与限额字段 |
| OpenRouter | 聚合入口、所选模型、可取得的实际路由／底层提供商、费用和 usage | 不能把聚合品牌当作唯一数据接收方；未验证的路由变化不得静默扩大外发范围 |
| 火山 | 实际方舟区域、端点、模型标识、流式及用量字段 | 品牌名称不能直接替代部署端点，也不保证每种模型相同能力 |
| OpenAI | 实际 API 与模型、可计费推理输出上限、用量及中断行为 | 不把最终 usage 缺失记为零，不以提示词保证执行搜索 |

每个允许模型记录 `providerId / modelId / endpointRef / capabilityVersion / priceVersion / status`。至少验证输出计费上限、上下文计数、用量解释和费用上界；无法可靠约束 2,000 个可计费输出 tokens 或其他既定限制时，不进入允许清单。首版禁用额外原生联网与工具计费，真实搜索由应用统一执行。

## 3. 准入、调用与核对流程

### 原子准入

1. 先检查可信账号、Agent／知识访问、问题和安全查询，拒绝明显无效请求；重放原请求不得重复预占。
2. 按计划调用图计算保守上界：完整输入（含系统、历史、知识、网页）、最大计费输出／推理、最多两次搜索、查询 embedding，以及实际适用附加费。首次准入时证据尚未取得，按允许的 8,000 输入 tokens 上界预占，不能先做付费检索再补预算；获得证据后仍不得超过已预占边界。未知缓存命中按保守价格；最终金额含 20% 缓冲且仍不得超过单次 ¥0.50。
3. 在 assistant 本地数据库事务中同时检查速率、账号／全局运行槽、成功次数占位、账号日预算和平台日／月预算。成功后创建 Reservation；任一条件不足则整体拒绝，不能只扣次数却没有预算。
4. 多账号和多个 Agent 竞争相同平台余额时，锁定／条件更新相同预算记录，以数据库结果决定是否放行；禁止先读余额再异步扣减。金额使用明确最小单位或定点数，不用浮点累计金额。
5. 每次外部尝试绑定 reservationId 与 attemptId。后续步骤若将突破原上界，停止本次新增调用，不借“重试”提高预算或调用次数。

用户全日成功次数跨课程、Agent、提供商合计；购买课程不增加次数。发起速率建议以滚动一分钟计数，成功次数以 Asia/Shanghai 自然日归属。频率拒绝、并发拒绝和预算拒绝分别向用户解释，不创建无限等待队列。20 次成功上限不保证每人一定可用满，成本限制可能先触发。

### 结算与未知费用

| 事实 | 成功次数／本地运行槽 | 成本处理 |
| --- | --- | --- |
| 完整答案持久化 | 消耗成功次数占位一次，释放运行槽 | 按可靠最终 usage 结算，释放已确认多占部分 |
| 完整“证据不足”答案 | 同上，属于已完成回答 | 照实结算，不能因为答案短就计零 |
| 搜索失败／生成失败／取消 | 释放成功次数占位和本地运行槽 | 已发生调用照实记账；未发送部分可释放；已发送但未知部分保留 |
| 上游失联、断流、usage 缺失 | 不以超时自动记为成功 | 状态为 `pending_reconciliation`，保留足够预占，24 小时仍未知转人工 |
| 供应商实际成本超过预占 | 不改写用户结果事实 | 全额记录差额并阻止进一步超额调用，告警排查价格或用量解析；不截断金额伪装守住上限 |

AnswerRun 的用户终态与费用终态独立。取消可能已经来不及阻止供应商计费；租约过期可释放本地执行权，不能抹除未知成本。相同供应商请求和结算事件幂等处理；已经确认的成本不能因迟到旧响应重复入账。

### 跨周期与后台任务

每个请求固定归属准入时的日／月周期。未决费用在新周期继续形成风险占用；查明后更新原周期并解除相应风险占用，不能重置归零，也不能把同一费用永久同时记在两个周期。

知识解析、embedding 与索引重建共用平台日／月预算，同时占用后台每日子限额；子限额在平台 ¥100／日之内，不额外叠加。后台不消耗学员成功次数，缺预算暂停并保留任务状态；内容哈希和源版本去重。未获授权的转写能力不会因为预留费用类型而自动成为 MVP 功能。

## 4. 接口与数据契约

以下为设计接口；Go DTO 与 Swaggo 注释随实现生成，禁止手工维护前端类型副本。

| 入口 | 输入 → 输出 | 约束 |
| --- | --- | --- |
| `provider.Generate(ctx, GenerationInput) (GenerationResult, error)` | 实际模型、输入证据、输出上限、截止时间、attemptId → 正文／终态、上游请求 ID、实际模型与 usage | 适配器消费已选协议；不自动重试或切换提供商，不发起隐藏工具调用 |
| `usage.Reserve(ctx, ReservationInput) (Reservation, error)` | requestId、kind、userId?、模型／价格版本、调用上界、周期 → reservationId、预占金额、可执行边界 | `kind=answer / index_job`；幂等键绑定输入哈希；后台不占学员次数 |
| `usage.Reconcile(ctx, SettlementInput) (Settlement, error)` | reservationId、attemptId、providerRequestId、usage／账单证据、结果状态 → 已确认成本、剩余未知预占、核对状态 | 只能释放有证据未发生部分；按价格快照结算，禁止用当前价格重写历史 |
| `GET /api/assistant/v1/models` / `listModels` | 可见范围 → 已启用 provider/model/能力摘要 | 学员不能提交清单外模型；管理端可看失效原因，均不返回凭据 |
| `GET /api/assistant/v1/usage` / `getUsageSummary` | 当前周期 → 本人次数／预算限制及原因；管理员授权视图含平台汇总 | 普通用户不能指定他人身份或获取全平台账单明细 |
| `PATCH /api/assistant/v1/management/budget` / `updateBudget` | `{expectedVersion, limits, effectiveAt, reason}` → 新配置版本 | 仅管理员，操作留痕；不能回改历史，降低额度不能释放既有未知成本 |
| `GET /api/assistant/v1/management/reconciliations` / `listReconciliations` | 周期／状态 → 待核对调用及证据摘要 | 仅管理员；不包含会话全文或原始密钥 |

`GenerationInput` 和 `GenerationResult` 是 assistant 内部类型；供应商原始结构由各适配器解码后收敛，保留必要原始用量证据供核对。`ReservationInput` 以服务端可信金额和调用上界为准，不接受学员自报价格、token 数或预算。

本域数据包含 ModelConfig、PriceVersion、BudgetConfigVersion、BudgetPeriod、Reservation、ProviderAttempt、Settlement、ReconciliationItem。价格版本保存原币种、单位价格、有效期、汇率来源／时点和适用费用项；缺价、过期或无法算上界时暂停对应能力。汇率或供应商价格需要运行时维护，本设计不写死“当前价格”。

费用控制台区分已确认、待核对和预占，不把估算当账单。平台到 80% 告警，到 100% 或不足新预占即停止新增付费任务；已预占任务按原边界收尾。停用 AI 不阻塞账号、购买、播放或社区。告警与运营处理先复用站内管理入口，不另建监控产品。

## 6. 实施与恢复门禁

先用提供商官方协议样本验证四家解析，再完成预算与结算的竞争／故障测试；之后才允许知识入库和 Agent 在获授权环境中调用真实付费能力。真实验收逐家记录模型／接口／日期、搜索证据、usage 和费用；固定模拟响应不满足 AC-13。

进程重启依据持久化 reservation/attempt 状态恢复核对，不重新发送未知调用。价格配置可回退到仍有效版本，已经发生的成本不可回滚；预算降低后存量超额告警并限制新调用。数据库备份恢复应保留调用幂等键和未知费用，不能只恢复汇总余额。
