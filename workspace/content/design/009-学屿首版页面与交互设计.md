## 1. 结论与范围

首版按 **P01–P21 共 21 个独立页面模板**组织，其中 P02 话题详情为设计建议，其余承载已确认的业务入口。注册／找回、发帖／编辑、退款申请、处理任务详情以同页模式或弹层承载，不按操作数量继续拆页。页面 ID 是本设计稳定编号，动态内容和错误状态不另编号为页面。

首页是社区信息流。全局顶部依次为 **Logo＋学屿名称 → 社区／课程／我的学习 → 通知／头像**，底部 footer 承载必要帮助和政策入口。Agent 使用右下角 Logo 入口打开 **G01 全局问答面板**，没有用户 Agent 列表页、会话页或一级导航；管理员仍在管理页配置不同用途实例。

本轮完成文档与 Figma，覆盖完整浅色桌面稿、主要移动稿及必要状态。现有前端只有技术基线，所有新路由均是待实施设计，文档站不改为业务首页。工程迁移、业务代码、API、数据库、真实支付和付费调用不在本轮。

最新 R-30 将首版页面、组件与状态统一为无边框视觉。设计 010 维护唯一规则与后续组件映射，保留 Vercel 风格、官方 shadcn/ui Radix、Geist 及适用的 UIUXProMax 焦点／复用建议；不据此另建营销结构或主题副本。用户已确认本轮先同步 Figma 与实现规范，不修改 `frontend/`，继续沿用设计阶段。

## 2. 导航、角色与公共结构

### 2.1 全局与管理导航

| 区域 | 桌面行为 | 移动行为与权限 |
| --- | --- | --- |
| Logo 与产品名 | 返回 P01 社区首页，使用设计 010 的品牌资源 | 保留辨识度与可操作标签，不能仅靠装饰图形表达目的 |
| 主导航 | 社区、课程、我的学习；当前项有清晰选中态 | 采用官方 Sheet 收纳；不另引入长期占宽的全局侧栏 |
| 通知与头像 | 通知进入 P11；头像菜单含本人账号、订单及适用管理入口、退出 | 游客显示登录入口；未登录进入“我的学习”先认证，成功返回原目标 |
| 管理入口 | 头像进入本人获授权的管理入口；管理区顶部二级导航按资格显示 | 讲师仅课程与授权知识；账号、退款、举报、Agent 配置、全局模型费用只向管理员提供操作 |
| Footer | 帮助、购买／退款政策及必要站点信息；政策内容引用交易规则 | 位于内容后，不能遮挡正文或移动端操作；法律与政策正文须采用实际审定版本 |
| Agent 入口 | 右下角品牌 Logo 打开 G01；不放入主导航 | 小屏在 Sheet 中展开，保留关闭与返回原页面的能力，避让软键盘和安全区 |

显示管理入口不等于已获资源权限。角色决定能否进入管理能力，各领域继续核验对象归属。管理员配置 Agent 不意味着其资料权限可以授予所有提问者。

### 2.2 公开信息与登录返回

游客可读的帖子信息限于标题、作者昵称、分类、时间及**独立公开摘要**。摘要是专门可公开的字段，不能在前端截取登录后正文来生成，也不能夹带评论、付费知识或隐藏内容。P10 的正文与评论需登录；课程讨论仍须当前课程访问权。

课程介绍、价格及目录公开；视频、图文和讨论按原领域权限执行，公开目录不等于公开内容。SEO／GEO、页面元信息、结构化数据和公开检索仅使用公开字段；不凭爬虫身份放行全文，也不把受保护内容放进浏览器首屏数据后再用界面遮住。

从原操作进入 P05 时保留站内目标、当前筛选和必要位置；成功后回到目标并重新检查权限。目标已隐藏、删除或失权则呈现对应状态，不重定向到无权正文；站外地址不作为任意返回目标。

## 4. G01 全局 Agent 面板与编辑弹层

### G01 问答面板

Logo 入口可从社区、课程、学习和本人页面打开同一面板；打开与关闭不改变当前页面和滚动位置。游客打开先显示服务说明与登录动作，未验证用户先完成验证；开始问答仍按已发布实例、本人会话、授权知识与费用准入核验。

面板内显示当前服务用途和可访问来源范围；课程学习上下文可作为选择已发布课程实例的设计建议，不静默加入当前用户无权资料。不同用途仍复用通用 Agent，具体上下文选择规则实施前核验。管理员维护入口是 P19／P20，学员不获得提示词、密钥、供应商管理或知识绑定控件。

面板采用官方聊天组件 `MessageScroller`、`Message`、`Bubble`、`Trace`、`Marker` 与输入组合；来源采用官方 `Sheet`／`Popover` 等组件，知识与网页分别标识。面板与弹层必须有标题、键盘关闭和焦点返回，详细组件约束见设计 010。引用视图读取时再次判断权限，不以此前在答案里出现过为由放行。

| 状态 | 面板可观察结果 | 允许的恢复 |
| --- | --- | --- |
| 新会话／无历史 | 服务说明、问题输入、本人可用次数提示 | 输入提问；历史仅显示仍可读取的本人内容 |
| 运行中 | 明确检索／联网／生成阶段，显示取消 | 关闭面板只收起；取消是独立操作；再次打开查询同一运行，不重复发起计费 |
| 已完成 | 完整答案、知识和网页来源、依据范围 | 打开有权引用；主动重试／重新生成属于新尝试 |
| 搜索失败／安全外发被阻断 | 保留问题，说明无法完成联网；不展示正常纯 RAG 答案 | 用户主动重试重新准入；不静默换供应商 |
| 成功零网页结果 | 明示未找到相关网页；有授权知识时可回答，无证据时说明不足 | 不伪造链接，不把服务错误归为零结果 |
| 知识服务失败／来源失权 | 说明知识暂不可用或内容不可访问，不冒充完整课程回答 | 可重试服务故障；失权引导回课程／账号入口 |
| 模型超时、断流或取消 | 未完成／已取消，未完成不计成功问答；不承诺调用未计费 | 主动重试创建新尝试；原未知费用仍核对 |
| 次数、并发或费用受限 | 给出具体受限原因与稍后使用指引，不能表示买课会增加次数 | 课程、交易、社区仍可用，不引导充值或钱包 |
| Agent 停用／历史失权 | 不发起新问答；受限历史正文及引用隐藏并说明 | 返回当前可用页面，不沿旧会话绕过权限 |

超时、次数、成本及恢复数值以 Agent／费用 PRD 为唯一来源，本页不复制参数表。阶段和完整答案的呈现是设计方案，不额外承诺逐字流式交付。

### 其他复用弹层与模式

| 场景 | 承载方式 | 关键约束 |
| --- | --- | --- |
| 发帖／编辑、评论／单层回复 | 帖子编辑 `Sheet`＋Tiptap；评论在原上下文精简编辑 | 正文支持已确认的标题、列表、引用、链接、代码与图片；评论建议保留基本文本、链接和代码，不复制全套工具栏；具体精简集合为设计建议 |
| 收藏、赞踩 | 官方 `Button`／`ToggleGroup` 组合 | 赞踩只能为赞／踩／未表态之一，可取消；目标仅帖子和回复，收藏仅帖子；失败回退并提示 |
| 退款申请／撤回、举报、管理理由 | `Dialog`／`Sheet`＋`FieldGroup`／`Field` | 提交失败保留输入；相同请求不重复办理；危险操作使用 `AlertDialog` |
| 上传任务、知识来源／版本、通知目标异常 | 当前页的 `Sheet`、`Alert`、`Progress` | 保持当前对象上下文，区分处理中、已完成未发布与真正可用 |
| 条款／退款政策阅读 | 购买页中可打开的文档视图 | 使用实际政策版本；不为凑页面数量预建新的营销页 |

Tiptap 的编辑状态不授予发布或资源权限。富文本渲染、图片访问、外链及内容保存按领域服务检查；不允许任意 HTML／脚本进入内容。正文长度、图片限制、保留与冲突细节仍按需求 009 的剩余项落实。

## 5. 关键原型路径与状态一致性

1. **发现与登录**：P01 话题筛选 → P10 公开预览 → P05 登录 → 返回 P10 正文；失败保留目标，隐藏／失权目标不显示旧正文。P02 作为相同信息结构的可分享话题模板。
2. **购买与学习**：P03 搜索／分类 → P04 → P09 购买确认／服务端支付结果 → P06／P07；服务端未知时停留查询状态，不能因浏览器返回成功展示已购。
3. **退款与访问**：P09 申请 → P15 审核与渠道处理 → P09 结果；申请和处理中保留权益，成功只撤对应购买；新购权益不被旧退款通知覆盖。内容撤回与退款是否完成分别显示。
4. **供课**：P12 → P13 编辑／上传 → 素材可用 → 讲师提交 → 管理员审核发布；上传或新版本处理失败不覆盖当前交付版，未发布草稿不出现在 P03／P04。
5. **社区**：P01 发帖 → P10 回复／赞踩／收藏／举报 → P11 通知；作者编辑只作用本人内容，隐藏内容在列表、详情、通知与公开摘要一致失效。
6. **知识与问答**：P17／P18 授权来源处理并显式发布 → 管理员 P19／P20 绑定发布 → G01 本次权限与费用准入、RAG 和真实搜索 → 答案及来源；未发布、撤回或失权内容不得进入回答及历史重读。
7. **费用恢复**：P21 达到限制或暂停新增 AI → G01 明确受限、P18 付费处理暂停；其他学习与社区继续可用。查询既有运行不增加新调用，未知费用保留核对。

所有列表和详情均覆盖 `Skeleton` 加载、`Empty` 空态、`Alert` 失败／权限原因、可恢复操作与提交中禁重复状态。表单用官方 Field 语义标记错误；键盘、焦点、图标标签和移动触达要求统一见设计 010。
