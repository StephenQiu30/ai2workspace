## 社区首页

打开 `/` 就能读到最近发布的讨论、服务说明和选课问题。服务展示区从全站公开服务帖读取最近四项，按标题切换封面说明，点击进入相应服务帖。桌面首行并排展示封面、目录与社区发布区，下方接讨论和课程。移动端先看紧凑封面，再发帖或阅读讨论。“浏览课程”始终可达。`/community` 兼容旧入口并保留筛选、页码与咨询上下文。[桌面首页](https://www.figma.com/design/3RvT2iBZxUtBGrTqgxNEnd?node-id=93-85)、[移动首页](https://www.figma.com/design/3RvT2iBZxUtBGrTqgxNEnd?node-id=93-2678)

| 发布意图 | 需要填写 | 发布后的去向 |
| --- | --- | --- |
| 写讨论 | 标题、公开摘要、富文本正文，可选择话题 | 回到信息流第一页，按时间显示新帖 |
| 发服务 | 服务名称、公开介绍、交付内容或联系说明 | 服务帖进入信息流，可以按“服务发布”筛选，在详情下咨询 |
| 问课程 | 问题、公开摘要、正文 | 进入课程咨询话题。从课程详情进入时预填课程名称，允许修改 |

三种意图共用编辑器。公开摘要独立编辑，游客只能读公开信息。验证邮箱的成员可发布，发送失败保留草稿。服务帖按社区内容审核。正式收款的服务商品另由运营配置，发帖不会自动收款或授予权益。[服务编辑态](https://www.figma.com/design/3RvT2iBZxUtBGrTqgxNEnd?node-id=99-2495)、[课程咨询态](https://www.figma.com/design/3RvT2iBZxUtBGrTqgxNEnd?node-id=99-2596)、[社区与治理 PRD](../prd/005-社区互动与内容治理产品需求.md)

## 课程、会员与服务

| 场景 | 学员的操作 | 状态与交付 |
| --- | --- | --- |
| 单课 | 搜索或筛选 → 查看价格、课表 → 免费试看、购买或咨询 | 服务器确认付款后开放已发布课时。普通停售保留已购权益，退款成功只撤回本次授予 |
| VIP | 查看含课清单、价格、期限 → 确认订单 → 查看会员中心 | 本稿采用一次支付固定期限、手动续费。到期保留进度，仍有单购权益的课程可继续学习 |
| 线上服务 | 阅读交付内容、时限与材料要求 → 购买 → 提交材料 → 收到交付 | 订单显示待提交材料、等待交付、已交付。管理员在履约页面查看材料并交付 |
| 支付待确认 | 查询原单 | 等待渠道结果期间保留原订单，查询和刷新必须幂等。成功页展示本单商品和下一步 |

原型举例使用单课 ¥99、30 天会员 ¥59、单次分镜点评 ¥199。实际价格、会员期限、包含课程与服务条款由运营决定。会员调价只影响新单，已付订单保存约定；续费起点、已购期内的课程移出、会员与服务售后规则须在正式销售前确定。[课程详情](https://www.figma.com/design/3RvT2iBZxUtBGrTqgxNEnd?node-id=93-421)、[VIP](https://www.figma.com/design/3RvT2iBZxUtBGrTqgxNEnd?node-id=93-485)、[服务详情](https://www.figma.com/design/3RvT2iBZxUtBGrTqgxNEnd?node-id=93-529)、[支付待确认](https://www.figma.com/design/3RvT2iBZxUtBGrTqgxNEnd?node-id=97-1921)、[订单与退款 PRD](../prd/004-交易退款与权益产品需求.md)

## 运营、权限与工程边界

管理员可开任意主题的课程，设置课表、试看课时和售价，审核讲师稿件；单课、会员方案、服务商品分别配置。课程讨论和播放均重新校验当前访问权。社区回复、点赞、收藏、举报与通知沿用社区领域规则。[管理工作台](https://www.figma.com/design/3RvT2iBZxUtBGrTqgxNEnd?node-id=93-1975)、[课程定价](https://www.figma.com/design/3RvT2iBZxUtBGrTqgxNEnd?node-id=93-2214)、[会员方案](https://www.figma.com/design/3RvT2iBZxUtBGrTqgxNEnd?node-id=93-2263)、[服务配置](https://www.figma.com/design/3RvT2iBZxUtBGrTqgxNEnd?node-id=93-2316)、[课程与媒体 PRD](../prd/003-课程与媒体学习产品需求.md)

| --- | --- |

业务接口由 Go DTO 与 Swaggo 生成，前端消费生成调用。社区服务拥有帖子、公开摘要和话题；学习服务拥有目录和进度；交易服务拥有订单、价格及权益。首页发布、服务帖筛选与课程咨询已接入现有社区接口。会员收款、服务商品结算及履约目前交付到交互原型。

### 公开信息与登录返回

游客可读的帖子信息限于标题、作者昵称、分类、时间及**独立公开摘要**。摘要是专门可公开的字段，不能在前端截取登录后正文来生成，也不能夹带评论、付费知识或隐藏内容。P10 的正文与评论需登录；课程讨论仍须当前课程访问权。

课程介绍、价格及目录公开；视频、图文和讨论按原领域权限执行，公开目录不等于公开内容。SEO／GEO、页面元信息、结构化数据和公开检索仅使用公开字段；不凭爬虫身份放行全文，也不把受保护内容放进浏览器首屏数据后再用界面遮住。

从原操作进入 P05 时保留站内目标、当前筛选和必要位置；成功后回到目标并重新检查权限。目标已隐藏、删除或失权则呈现对应状态，不重定向到无权正文；站外地址不作为任意返回目标。

### G01 问答面板

Logo 入口可从社区、课程、学习和本人页面打开同一面板；打开与关闭不改变当前页面和滚动位置。游客打开先显示服务说明与登录动作，未验证用户先完成验证；开始问答仍按已发布实例、本人会话、授权知识与费用准入核验。

面板内显示当前服务用途和可访问来源范围；课程学习上下文可作为选择已发布课程实例的设计建议，不静默加入当前用户无权资料。不同用途仍复用通用 Agent，具体上下文选择规则实施前核验。管理员维护入口是 P19／P20，学员不获得提示词、密钥、供应商管理或知识绑定控件。

面板采用官方聊天组件 `MessageScroller`、`Message`、`Bubble`、`Trace`、`Marker` 与输入组合；来源采用官方 `Sheet`／`Popover` 等组件，知识与网页分别标识。面板与弹层必须有标题、键盘关闭和焦点返回，详细组件约束见设计 010。引用视图读取时再次判断权限，不以此前在答案里出现过为由放行。

| 状态 | 面板可观察结果 | 允许的恢复 |
| --- | --- | --- |
| 新会话／无历史 | 服务说明、问题输入、本人可用次数提示 | 输入提问；历史仅显示仍可读取的本人内容 |
| 运行中 | 明确检索／联网／生成阶段，显示取消 | 关闭面板只收起；取消是独立操作；再次打开查询同一运行，不重复发起计费 |
| 已完成 | 完整答案、知识和网页来源、依据范围 | 打开有权引用；主动重试／重新生成属于新尝试 |
| 搜索失败／安全外发被阻断 | 保留问题，说明无法完成联网；不展示正常纯 RAG 答案 | 用户主动重试重新准入；不静默换供应商 |
| 成功零网页结果 | 明示未找到相关网页；有授权知识时可回答，无证据时说明不足 | 不伪造链接，不把服务错误归为零结果 |
| 知识服务失败／来源失权 | 说明知识暂不可用或内容不可访问，不冒充完整课程回答 | 可重试服务故障；失权引导回课程／账号入口 |
| 模型超时、断流或取消 | 未完成／已取消，未完成不计成功问答；不承诺调用未计费 | 主动重试创建新尝试；原未知费用仍核对 |
| 次数、并发或费用受限 | 给出具体受限原因与稍后使用指引，不能表示买课会增加次数 | 课程、交易、社区仍可用，不引导充值或钱包 |
| Agent 停用／历史失权 | 不发起新问答；受限历史正文及引用隐藏并说明 | 返回当前可用页面，不沿旧会话绕过权限 |

超时、次数、成本及恢复数值以 Agent／费用 PRD 为唯一来源，本页不复制参数表。阶段和完整答案的呈现是设计方案，不额外承诺逐字流式交付。
