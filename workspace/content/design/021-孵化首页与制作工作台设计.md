## 视觉方向

首页借鉴 Apple 介绍页的编辑节奏。第一屏用一句话与一张作品主图建立印象。后续区块分别回答「是什么作品」「怎么做出来」「如何参与」。使用原始画面色彩与留白，白底和浅蓝背景承担章节分隔。参考 [MacBook Air 介绍页](https://www.apple.com.cn/macbook-air/)与 [iPad Pro 介绍页](https://www.apple.com.cn/ipad-pro/)。

工作台沿用同一套字形、品牌蓝和留白。标题与封面帮助成员快速识别当前项目，行内状态和操作形成扫描路径。蓝色集中在主操作、链接和当前制作阶段。作品插画使用既有《雨停之前》概念图。片名、进度、版本和任务内容均为视觉稿示例。

## Landing Page

公开首页服务于观看、制作学习和授权共创。访客从首页到 IP 档案，再到作品详情或公开拆解。有制作权限的成员可从主导航或账号菜单进入工作台，未登录访客经登录后继续。

| 顺序 | 内容和呈现 | 行为 |
| --- | --- | --- |
| 1. 首屏 | 品牌定位「学屿原创 IP 孵化中心」，主张「让一个故事，成为一部作品」，一张 IP 主图 | 首发样片已经公开时，主操作「观看样片」进入作品详情。准备阶段使用「了解首发 IP」定位至 IP 区块。公开拆解可读时提供「看制作拆解」 |
| 2. 作品与档案 | 片名、一句话设定、样片或发布状态 | 「查看 IP 档案」进入角色、世界观和作品列表。准备阶段用「样片准备中」说明状态，展示获准公开的概念图 |
| 3. 制作拆解 | 以同一镜头串联剧本、分镜、成片中的一项取舍 | 首页呈现短摘录，完整拆解在对应作品下读取。拆解与所引用的发布版本对应 |
| 4. 共创 | 写清发布中的题目、投稿对象和授权素材边界 | 有有效题目时，「查看共创规则」进入详情。准备阶段提示开放状态，保留一个清晰的下一步条件 |

### 首页状态

- 尚无可公开 IP 时，首屏保留品牌主张和准备提示，作品卡、拆解与共创随可公开内容逐步出现。
- IP 已公开而样片尚未正式发布时，访客可进入 IP 档案。概念图注明“概念插画”。拆解区以单独获准公开的内容为准。
- 正式发布后切换主操作。详情页按实际授权提供播放或试看，使用封面、时长、字幕或可阅读文本。主动播放才请求媒体。
- 作品撤下或素材许可失效时，更新首页可见区块。旧详情链接展示当前状态，媒体访问按授权重新校验。
- 公开内容读取失败时，保持页面标题与导航可用，在对应区块提供重试，加载占位与完成后的内容尺寸保持接近。

## Dashboard

Dashboard 定位为创作者制作工作台。成员进入后先找到当前集和下一步，再处理需要自己确认的事项。项目编辑、任务重试和审片确认分别进入对应业务界面。

| 区域 | 数据 | 主交互 |
| --- | --- | --- |
| 当前制作 | 当前可访问项目、集、制作阶段和已选版本。优先恢复最近一次可访问的集和视图 | 「继续制作」恢复到对应集及视图。上次位置失效时，进入项目当前阶段并说明已切换 |
| 待处理 | 当前成员可操作的待审镜头和失败任务。每行显示类型、关联集及版本或阶段 | 「查看待审」打开预览，确认后可进入完整审片。「查看任务」打开任务详情，从该任务发起重试 |
| 制作项目 | 当前工作区内成员有权访问的项目、当前集及制作状态 | 「打开项目」进入对应项目。仅有一个 IP 时直接列出，保留必要的信息 |
| 制作资料 | 当前 IP 的设定和授权素材 | 进入相应工作面，资料沿用当前 IP 上下文 |

### 待审预览

桌面右侧 `Sheet`、移动底部 `Sheet` 展示镜头名、集与分镜版本、候选画面和审片范围。桌面保留身后的工作台层次，移动面板允许内容独立滚动。关闭时回到打开该行的位置，将焦点归还「查看待审」。正式审核进入既有审片页。提交时按当前版本重新校验，发现变化时提示成员重新确认。

### 工作台状态

| 场景 | 界面响应 |
| --- | --- |
| 首次进入或暂无可用项目 | 展示项目空态。具备创建权限时提供「新建制作项目」，其余成员显示加入工作区或获授权后的使用提示 |
| 有项目而暂无待办 | 显示「暂无待处理事项」，继续制作与项目入口照常可用 |
| 项目或任务内容加载失败 | 在对应区域提供重试。已加载区域继续可用 |
| 会话过期或权限变化 | 会话过期进入登录并携带原本的安全回跳地址。权限变化时返回可访问的项目列表，并说明该项当前不可访问 |
| 分镜版本变化 | 关联镜头按实际状态显示待复核。保留原版本作为核对依据，禁止将旧候选直接认作已确认版本 |

## 布局、交互与验收

- 桌面在 `BasicLayout` 内容边界内排版。首页章节内边距随视口收放，主视觉出现在首屏。工作台从 1024 px 起可用两栏，窄至平板时按正文顺序堆叠。移动两侧至少 16 px，顺序为当前制作、待处理、制作项目、制作资料。实施验收覆盖 320、390、768 和 1440 px。
- 首页使用段落锚点和正常滚动。键盘触发段落跳转时聚焦对应标题。降低动态效果偏好开启时直接跳转。封面提供与语境匹配的替代文本，正文、导航和操作可独立于作品图理解。
- 页面一个一级标题，章节按语义顺序排列。焦点使用 `ring` 令牌。正文、链接和状态文案按 WCAG AA 验证对比度。点击和触控目标至少 44 px 高。阶段和审片结果使用可读文案表达。
- 设计稿验收检查首屏视觉重心、两端信息顺序和审片往返。产品验收覆盖待发布与已发布、发布撤回、无项目、任务失败与恢复、版本变化及不同权限。公开字段和媒体访问以[作品发布设计](./015-作品发布与制作学习设计.md)为准，审片与任务按[成片制作设计](./012-剧本分镜与成片制作设计.md)核验。
