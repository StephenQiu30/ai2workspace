## 页面与交互

公开首页以一个正式作品带出原创 IP。在 **IP 专页** 浏览角色、世界观和作品集，在 **作品详情** 查看正片或试看、制作拆解、购买和二创入口。制作人员从工作台进入 **发布审核**，并在预览里切换游客及购买者可见范围。画面、标题和作者构成公开页主要层级，使用[品牌与界面规范](./010-学屿品牌与界面设计规范.md)的留白、对齐和可访问焦点。

| 阶段 | 可观察结果 |
| --- | --- |
| 准备 | 选择审片通过的成片，填写封面、介绍、试看和可公开的拆解，确认实际外部使用范围 |
| 审核 | 显示缺失媒体、过期设定或素材使用限制。审核通过后可正式发布 |
| 已发布 | 稳定详情地址展示一版正式快照。访客看到允许公开的内容，付费内容按权益校验 |
| 更新／撤下 | 新稿完成审批后切换版本。撤下后关闭新的公开访问入口，已购交付按渠道、权利及售后状态协同处理 |

## 职责与数据

制作域内发布功能拥有正式发布快照，包含作品 ID、已审成片版本、试看、封面、正文及拆解版本。拆解按公开或权益可见标记。发布动作还要校验媒体可交付和素材使用范围。公开接口仅返回公开字段。权益内容在服务端检查发布状态、媒体控制和业务权益，购买身份来自账号会话。[受控播放参考](./003-课程与媒体学习设计.md#受控播放与进度)

D-01 公开快照与内部工作稿分离。制作拆解只从团队明确选择、复核并批准的过程内容发布。公开 SEO 和搜索按相同字段读取，内部运行、草稿媒体地址和未公开提示词保留在工作区。

D-02 区分停售和撤回。作品发布域输出当前可交付状态及其时间信息。已售商品绑定约定内容，交易域依据[自有作品付费与交付](../design/017-自有作品付费与交付设计.md)显示访问或售后状态。试看可启用单独的公开媒体或明确公开片段，不开放完整付费媒体地址。

关联讨论和二创由[作品二创与讨论](../design/016-作品二创与讨论设计.md)维护，制作输入来自[剧本分镜与成片制作](../design/012-剧本分镜与成片制作设计.md)。

## 非功能设计与验证

| 需求 | 设计措施与验证方法 | PRD 验收 |
| --- | --- | --- |
| NFR-01 | 对外页面、搜索与媒体授权从公开快照读取；校验权益后签发完整媒体，失败返回对应状态 | AC-11 |
| NFR-02 | 先验证成片、素材和拆解，再切换发布指针，允许回退到仍可合法交付的版本；撤回后重新校验媒体 | AC-12 |
| NFR-03 | 沿用界面规范的焦点、断点和媒体控件。公开页发布时确认字幕或可读文本等价信息 | AC-13 |

## 验证映射

| 需求／验收 | 验证方法 |
| --- | --- |
| R-01／AC-01 | 验证未审片或素材权利未确认时发布被阻止，修复后可发布 |
| R-02／AC-02 | 从首页进入作品，验证试看、拆解、讨论和二创入口与公开字段 |
| R-03／AC-03 | 更新正式版本、模拟撤下并核对稳定地址、已购入口和售后状态 |

撤下后已购内容的处理与审核责任待评审。发布渠道、版权和媒体验收须记录实际证据。
