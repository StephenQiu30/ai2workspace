## 页面与主流程

在制作工作台打开 **IP 设定与素材**。首版包含 IP 概览、设定编辑、素材详情和开放范围编辑。管理员建 IP 并邀请制作人员。创作者保存角色、世界观、时间线和媒体，获授权的审阅者将其中一版标为正式。对外开放时预览访客或二创作者能看到和用到的内容。

| 状态 | 页面反馈与恢复 |
| --- | --- |
| 草稿／待确认来源 | 显示当前版本、来源欠缺字段和可编辑动作。制作引用可以显式选择有权限的内部素材 |
| 正式／开放 | 显示版本、确认人、使用范围和具体用途。旧版本仍可供获授权的制作人员追溯 |
| 已撤回／上传处理失败 | 说明受影响引用。撤回后阻止新增使用，上传失败可从原条目重试 |

## 职责与数据

| 对象 | 设计 |
| --- | --- |
| IP 与成员 | 拟由制作域维护 IP 及成员资源权限，账号会话沿用身份域。每个查询和变更按所属工作区、IP 和权限验证 |
| 设定及版本 | 设定条目有稳定标识。内容、确认状态与确认记录属于具体版本。下游用条目标识和版本标识引用 |
| 素材及使用范围 | 素材版本记录原文件引用、来源、署名、用途、范围及状态。浏览、下载、站内二创、公开发布和商用交付分别判断 |
| 文件访问 | 复用受控上传和读权限思路。下载与预览经过服务端授权，短时地址按实际可访问范围签发 |

拟将 IP、作品制作和发布置于同一制作域的独立功能包。首次只验证自营工作区，同时以工作区和 IP 标识隔离项目数据。最终部署划分待评审。已有身份和媒体设计只提供可复用机制，具体上传格式、媒体供应商和许可条款在开发前确认。[身份设计](./002-账号与访问控制设计.md) · [媒体设计](./003-课程与媒体学习设计.md)

## 版本与撤回

D-01 选择明确的版本引用。修改正式设定时生成新版本，历史镜头仍指向制作时采用的版本，索引同步见[制作知识库与RAG](../design/013-制作知识库与RAG设计.md)。

D-02 撤回先改变权威可用状态，再让检索、公开页面及投稿重新校验。已有成片关联到被撤材料时记录阻塞并交给发布负责人处理，发布和售后分别见[作品发布与制作学习](../design/015-作品发布与制作学习设计.md)、[自有作品付费与交付](../design/017-自有作品付费与交付设计.md)。许可字段及审阅记录的设计参考影视制作在各阶段记录权利来源的做法。[WIPO 影视权利清理指南](https://www.wipo.int/web-publications/rights-clearance-a-guide-for-independent-filmmakers/en/2-rights-clearance-from-idea-to-distribution.html)

## 非功能设计与验证

| 需求 | 设计措施与验证方法 | PRD 验收 |
| --- | --- | --- |
| NFR-01 | 读取端统一校验工作区、角色与资源用途；文件签发前重查授权。以受控测试文件验证直接访问与撤权 | AC-11 |
| NFR-02 | 更新使用预期版本条件；确认事件、正式指针与历史引用在同一提交中校验 | AC-12 |
| NFR-03 | 记录许可变更及受影响内容标识，访问许可记录需要管理权限；公开只展示获准的署名和说明 | AC-13 |

## 验证映射

| 需求／验收 | 验证方法 |
| --- | --- |
| R-01／AC-01 | 同一角色建立两版，确认正式指针与历史镜头引用分别正确 |
| R-02／AC-02 | 检查素材来源、署名及版本，验证无权用户拿到地址也不能新取文件 |
| R-03／AC-03 | 撤回二创权限后重试领取和投稿，核对受影响作品提示 |
