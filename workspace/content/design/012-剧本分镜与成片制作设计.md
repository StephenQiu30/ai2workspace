## 制作页面

登录后进入 **制作项目**，按 IP 找作品，看到正在编辑的集、待审镜头和失败任务。单集工作台内设剧本、分镜、镜头素材、审片与导出五个视图。各视图共享当前集和版本状态，切换后仍能返回原编辑位置。

| 环节 | 主要操作与产物 |
| --- | --- |
| 剧本 | 建立作品和集，填写简报，按场写动作、对白。保存修订并由编剧选择用于分镜的版本 |
| 分镜 | 按场划分镜头并排序，填写画面、景别、时长、角色与声音需求。选择用于制作的分镜版本 |
| 镜头 | 逐镜上传或运行获授权的生成任务，选择画面、配音和字幕版本，预览与标记待复核 |
| 审片 | 汇总时间轴和素材状态，按镜查看意见，确认一份可合成的版本 |
| 成片 | 由平台按审片版本合成画面、配音与字幕，预览并导出 MP4。将通过复核的成片版本交给发布流程 |

首个验收作品建议为一集 30–60 秒动态漫，具体规格见需求记录 Q-01。首版合成器只需完成按镜头顺序拼接、配音和字幕。带完整素材的正常路径必须能在平台内得到成片，上传预制整片可作为独立导入场景，首版验收使用平台合成路径。

## 职责与数据

制作域拥有作品、集、场、镜头、剧本版本、分镜版本、素材选择和成片版本。IP 设定和素材使用见[原创IP设定与素材](../design/011-原创IP设定与素材设计.md)，Agent 与媒体任务记录见[制作Agent与任务编排](../design/014-制作Agent与任务编排设计.md)。沿用[媒体设计](./003-课程与媒体学习设计.md)的直传、处理状态和受控读取思路，拼接工件由制作域发布引用。具体合成工具、存储适配和可用规格待评审。

| 数据对象 | 约束与恢复 |
| --- | --- |
| 剧本场与镜头 | 场和镜头用稳定 ID 定位。修订时比较旧版与新版字段，标记依赖镜头、字幕及音轨为待复核；未引用该场的镜头保持可用 |
| 审片版本 | 记录剧本、分镜、镜头、字幕和音轨的确切版本。审片通过后冻结本次输入；继续编辑产生新草稿 |
| 合成任务 | 同一提交重复到达时返回同一任务；操作中展示进度。失败保留素材和审片版本，可重试该操作 |
| 成片版本 | 成功后保存媒体标识、时长与审片引用。若返回时原输入已过期，产物保留供核对，由人重新确认能否交付 |

## 非功能设计与验证

| 需求 | 设计措施与验证方法 | PRD 验收 |
| --- | --- | --- |
| NFR-01 | 保存明确返回版本；并发写使用预期版本，冲突可保留待合并的修改。用刷新、中断和并发提交测试 | AC-11 |
| NFR-02 | 长任务异步执行；记录排队、执行和失败阶段。以试点规格采集耗时，避免把等待绑定到页面请求 | AC-12 |
| NFR-03 | 持久化任务标识、输入版本和产物写入状态；可从同一任务恢复或按明确重试规则重建 | AC-13 |

## 取舍与验收

D-01 使用逐镜版本与最小合成功能。可以局部重做并核对差异，降低普通修改导致的返工范围。

D-02 正式发布以审片确定的成片版本为输入，发布审核和公开状态见[作品发布与制作学习](../design/015-作品发布与制作学习设计.md)。

| 需求／验收 | 验证方法 |
| --- | --- |
| R-01／AC-01 | 从简报创建剧本并保存两个版本，依据选定版本制作和重排分镜 |
| R-02／AC-02 | 修改一场对白，定位相应镜头音轨或字幕，再确认无关镜头仍可用 |
| R-03／AC-03、AC-04 | 用分镜、画面和声音在平台合成实拍或动画样片，复核播放、导出、失败重试和过期结果 |

验收使用项目自有或获准的素材。供应商、渲染规格和生产条件待评审，执行结果待记录。
