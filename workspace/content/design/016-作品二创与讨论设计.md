## 页面与主流程

从**作品详情**查看作品讨论与二创。经验证成员可发帖和回复。作品开启二创后，作者从明确的开放规则进入**二创项目**，预览可用素材并保存私有草稿。首版使用一个投稿格式验证流程，例如一页分镜。作者可以在平台编辑文字与排序并上传图片，提交时保存版本，按反馈再提交。

| 状态 | 页面行为 |
| --- | --- |
| 未开放／开放 | 未开放时说明当前状态。开放时展示允许的素材、用途、署名和提交格式 |
| 草稿／已提交 | 草稿归作者。只有投稿版本对审核者可见，作者仍可继续编辑后提交新版本 |
| 待修改／已通过 | 审核意见关联使用的投稿版本。公开后展示作者、原作、素材出处及二创标识 |
| 撤回／举报 | 作者、审核者和运营按各自权限撤回或处置。历史记录按权限可查，已撤作品的公开入口显示相应状态 |

## 职责与数据

既有 community 域保有讨论、回复及举报机制，拟增加经过校验的作品上下文标识。制作域的共创功能保存二创项目、原作版本、素材引用、投稿及审阅记录，分别对作者、审阅者和访客授权。[社区互动与治理设计](./005-社区互动与内容治理设计.md)

D-01 使用作品相关讨论及投稿。讨论和二创列表从作品详情访问。普通讨论关联原作作品 ID，二创提交同时保留制作所依据的正式版本，便于原作方更新设定后仍可核对旧稿。

D-02 作者开始时显示开放规则，提交与公开时服务端再次按用途校验。撤下原作或素材后，暂停继续使用和新公开操作，已公开二创置入运营复核。未确认如何处理旧稿时显示当前状态，不公开更多受限素材。规则来源见[原创IP设定与素材](../design/011-原创IP设定与素材设计.md)，公开原作状态见[作品发布与制作学习](../design/015-作品发布与制作学习设计.md)。

## 非功能设计与验证

| 需求 | 设计措施与验证方法 | PRD 验收 |
| --- | --- | --- |
| NFR-01 | 作者草稿与投稿快照分别授权；公开视图返回已审核公开版本，内部意见按审核或本人权限返回 | AC-11 |
| NFR-02 | 以固定投稿版本保存审阅快照；使用状态条件写入审阅与撤回。避免编辑回写旧投稿 | AC-12 |
| NFR-03 | 错误关联具体素材或字段；失败保留当前草稿、焦点与返回路径；清楚显示需要更换素材 | AC-13 |

## 验证映射

| 需求／验收 | 验证方法 |
| --- | --- |
| R-01／AC-01 | 从具体作品进入讨论、发布回复、回到原作，验证删除和举报后公开状态 |
| R-02／AC-02 | 领取许可素材、创建私稿、提交、审核退回与再提交。访客无法读取私稿 |
| R-03／AC-03 | 审核通过的二创显示来源和署名；撤回权限后阻断新提交与发布并形成复核记录 |

首批共创素材、发布条款和审核参与者待确认。二创报价、许可交易和分账属于后续商业验证。
