## 知识分类

- [原始需求](./requirement/00-原始需求导航.md)：用户诉求、明确确认、范围与验收来源。
- [设计](./design/00-设计导航.md)：技术方案、职责、取舍与技术验收条件。
- [PRD](./prd/00-PRD导航.md)：用户价值、功能范围、故事与产品验收条件。
- [实施计划](./plan/00-实施计划导航.md)：步骤、依赖、验证与必要证据；实施状态统一见根 BACKLOG.md。
- [调研](./research/00-调研导航.md)：外部事实、来源、核验日期、推断和限制。
- [部署运维](./operations/00-部署运维导航.md)：运行环境、部署配置、检查与恢复方法。
- [模板](./templates/00-模板导航.md)：设计、用户故事、测试场景与知识编写规范。
- [Skill](./skills/00-Skill导航.md)：项目能力与技能使用边界；工具安装和运行配置不进入知识正文。
- [工作流](./workflows/00-工作流导航.md)：可阅读的研发协作步骤，不承载工作流执行服务。

## 来源与边界

参考 Glowloom 当前 Workspace 的结构、官方组件与通用规范。Ai2sd 使用独立内容、稳定 ID 与 1140 本机端口。根 AGENTS.md、PROJECT.md、DESIGN.md、README.md、BACKLOG.md 各自承担唯一职责，保留在源码根目录。

需求主链为 requirement → design → prd → plan，跨领域依赖用链接表达。建议、待确认与已确认事项分开记录；实施状态只在根 BACKLOG.md 维护。
