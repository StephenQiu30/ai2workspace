## 语境

ai2workspace 是面向公众的学习交流平台，提供由管理员和受邀讲师供给的课程，以及基于知识库和能力配置的通用 Agent。本文仅定义业务术语，具体范围与确认记录见[需求记录](../requirement/001-学习社区与通用Agent需求记录.md)。

## 学习与交易

**学员**：使用平台课程进行学习和交流的用户。
_避免_：在同一业务语境交替使用“学生”“学习用户”指代同一角色。

**受邀讲师**：经平台邀请而取得课程供给资格的用户。
_避免_：将“已注册用户”等同于“讲师”。

**课程**：围绕一个学习主题组织并向学员提供的学习内容集合，也是单课销售所指向的对象。
_避免_：将“课程”与某个“视频文件”等同。

**章节**：课程内用于组织相关课时的内容单元。
_避免_：将章节和单个课时混称。

**课时**：学员进入并记录学习进度的具体学习单元，可包含录播视频和图文资料。
_避免_：将课时等同于视频文件或固定的时间长度。

**试看**：付费课程中被明确开放、可在购买前体验的内容范围。
_避免_：将“试看”称为整门“免费课程”。

**学习权益**：用户被允许访问某门课程及其相应受保护内容的资格。
_避免_：将“订单”“付款记录”“学习进度”当作权益的同义词。

## 智能服务与知识

**项目知识库**：保存本项目需求、设计、规范和协作资料的文档集合。
_避免_：与供产品 Agent 使用的“业务知识库”混称。

**业务知识库**：围绕明确知识范围整理、供 Agent 使用并有访问边界的资料集合。
_避免_：直接将整个项目文档网站称为已接入的 Agent 知识库。

**通用 Agent**：根据配置的角色、可访问知识库和联网搜索能力，为不同场景提供有依据回答的智能助手。
_避免_：将“Agent”等同于“课程问答框”或“只能检索的机器人”。

**Agent 实例**：面向某一用途配置和发布的 Agent，例如平台客服或某门课程的学习助手。
_避免_：将每个实例理解为一套独立产品或独立业务服务。

**联网搜索**：从外部互联网检索与问题相关的信息，作为本地业务知识之外的补充来源。
_避免_：将“联网搜索”称为对平台数据的“写入”或“代操作”。

**工具能力**：Agent 可以使用的一项明确能力；本专题当前指知识检索和联网搜索。
_避免_：使用“万能执行”“任意调用”代替明确的能力边界。

**引用来源**：支撑 Agent 回答的原始资料及其可定位位置。
_避免_：将模型自行生成的说明当作已存在的资料来源。
