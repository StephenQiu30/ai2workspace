## 1. 背景与问题

用户希望将 ai2workspace 建设为学习交流社区：围绕课程提供内容供给、购买学习和社交互动，并以通用 Agent 组合不同知识库和能力提供服务。客服与课程助手是应用场景，不构成两套专用 Agent 产品。

**工程现状**：2026-11-17 只读核对，仓库位于 `Ai2Workspace`，分支 `main`。当前具备 Fumadocs 项目知识库、Next.js 前端及 Go 服务技术基线；前端只有服务连接页面，后端只有健康检查和 Swagger。课程、交易、身份认证、社区、持久化和 Agent 业务尚未实现。依据为根 `PROJECT.md`、`frontend/src/app/page.tsx`、`frontend/src/features/service_status/service_status.tsx`、`backend/services/ai2workspace/internal/server/server.go`。历史工程初始化通过不代表新业务验收。

**用户与成功标准**：面向公众，不限定课程主题或职业人群；首版邮箱密码注册，以完整学习闭环与权限正确为成功标准。尚无用户访谈、转化率或留存基线，不能据此声称已验证市场需求。

S-01 原文：

> 1. 将我们的平台打造成一个学习交流的社区，主要的一些功能需要至少包括基本的CRUD
> 2. 我们的平台需要知识课程的播放上传以及学习，因此一些基本的社交，评论，点赞，点踩服务都是需要的，包括如何设计课程相关，视频播放相关等服务。
> 3. 我们需要基于 RAG 做智能的客服以及对应的学习的agent服务，比如我们可以做很多的课程的agent，基于我们的课程上下文回答学生提出的问题等等

> 2. 设计需要符合软件工程的规范

## 3. 目标与范围

### 已确认的产品方向

- 首版向公众开放邮箱密码注册，不限定某一课程主题或职业群体；课程由管理员和受邀讲师创建和维护。
- 首版支持人民币单课一次性购买、平台统一收款，保留免费课和试看；会员、套餐、讲师自动分账后续考虑。
- 完整社交地图包含帖子、课程讨论、评论／回复、赞踩、收藏、关注、通知、私信、举报和内容管理。首版交付讨论互动、收藏、必要通知、举报及管理；关注和私信后续交付。
- 通用 Agent 通过可配置角色、授权知识库和联网搜索服务不同场景；管理员／受邀讲师配置发布，学员使用。按 S-05 最新说明，首期围绕检索、联网与回答，不包含业务写入。个人知识库与 Agent 市场后续考虑。
- 首版采用课程／章节／课时、录播视频和图文资料、试看与进度恢复；购买后在平台持续提供课程期间可访问，普通下架停止新售但保留已购访问，退款人工审核并在退款成功后撤销相应权益。具体退款条件另行确认。
- 邮箱验证后购买和互动；支持找回密码；单层回复、互斥赞踩、站内通知、举报处置，课程讨论参与者须有课程访问权。
- 每次 Agent 回答都发起联网搜索；至少支持 DeepSeek、OpenRouter、火山、OpenAI。具体模型、搜索供应商和费用配额尚未确定。
- 本次交付需求文档与顶层架构方向；完整设计和 MVP 分期同时保留，不以未来能力为由提前实现基础设施。

### 本次工作边界

只编写与评审知识库文档，不编写业务代码，不创建业务服务或数据库，不接入真实支付、模型和媒体提供方，不提交、推送或发布。工程约束引用[统一规范](../standards/001-项目文档与设计规范.md#工程规范与目录设计)，不另写一套规范。

### MVP 候选主流程

讲师创建并发布课程 → 用户注册、浏览与试看 → 下单支付 → 获得学习权益 → 播放并继续学习 → 讨论与反馈 → 使用通用 Agent 基于授权知识与联网搜索获取有来源的回答。

Q13 已接受完整闭环与权限正确作为验收；其中原提问包含的“写入”按同轮 Q11 纠正移除。“浏览器显示支付成功”不能直接等同于权益生效，“上传完成”不能直接等同于视频可播放。

### CRUD 的业务含义

CRUD 是基本操作完整性，不代表所有对象都能任意删除或由所有用户修改。课程发布、内容下架、订单取消、退款、账号停用和知识撤回应分别定义状态；已发生支付及审核记录应保留必要追溯关系。此段是设计建议，具体规则进入 PRD 后确认，不能将“删除订单”解释为抹除支付事实。

### 完整需求地图中的待定项

以下能力已被识别，但没有默认纳入首版：课程分类与搜索、资料下载、字幕／转写、学习计划、测验与作业、学习完成标准、直播、证书、人工客服工单、运营数据与账号注销。AI 用量与费用控制已根据 S-07 进入本轮推荐设计，见 R-17。其余按真实用户问题决定首版、后续或不做；全文搜索产品、直播系统、考试系统、推荐算法等不因出现在地图中而成为实施要求。
