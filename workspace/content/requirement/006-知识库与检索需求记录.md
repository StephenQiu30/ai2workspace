## 1. 背景与问题

用户需要通用 Agent 根据不同的 RAG 知识库服务学习和客服等场景。管理员与受邀讲师必须能够维护资料及可用范围，使用者则应获得与自己当前权限相符、能够追溯来源的内容。若课程资料更新或撤回后旧内容仍被检索，答案会与实际学习内容及访问权限脱节。

上述是产品需求和设计风险，不是已观测的生产事故。工程当前只有技术基线，没有真实资料入库、检索质量或用户满意度证据。项目文档网站 `workspace/content/` 不是此业务知识库的默认数据源。

## 3. 目标与范围

首版让有权维护者完成资料登记、更新、处理状态查看、发布和撤回，向 Agent 提供有来源、版本和访问边界的检索依据。独立知识库可服务不同用途，课程关联只是其中一种来源。

| 范围 | 内容及限制 |
| --- | --- |
| 首版方向 | 管理端维护知识库及授权来源；资料导入、更新、处理状态、发布可用版本、检索引用与撤回 |
| 使用权限 | 管理员／受邀讲师只能维护获授权资源；学员只通过已发布实例使用自己当前有权访问的资料 |
| 来源边界 | 课程资料须明确授权接入；课程原文由课程域维护，讨论不自动成为可信知识，项目文档不默认镜像 |
| 后续能力 | 个人自建知识库、知识／Agent 市场；没有明确交付版本 |
| 未自动纳入 | 视频转写、OCR、PDF 或任意附件解析、网页爬取；播放视频不等于能够理解或检索视频内容 |
| 本域不负责 | Agent 角色和会话、每答搜索与生成、模型选择及预算账；分别由 Agent 和费用领域负责 |

## 4. 需求条目

| ID | 场景与诉求 | 来源 | 优先级与理由 | 确认状态 |
| --- | --- | --- | --- | --- |
| R-08 | 管理员／受邀讲师维护不同知识库，导入、更新、撤回资料并查看处理状态 | S-01、S-02、S-03 | 首版，为 RAG 提供可管理的内容依据 | 方向与维护者范围确认；资料来源类型、支持格式、大小及保留期限待定 |

R-08 的产品验收在本域 PRD FR-08／AC-08 定义：登记或处理完成不等于可用于回答；只有已发布且仍有权访问的资料可供检索。来源、版本和当前权限应可核对，删除、撤回或权益失效后不能继续从旧索引、引用或历史会话读取受保护内容。

上述权限落实同时受总 PRD 的 FR-11／AC-11 约束，恢复落实受 FR-12／AC-12 约束。本域不复制共同规则，也不把设计中的具体检索引擎、切片参数或状态名写成用户已经确认的需求。

## 5. 待确认问题与跨域依赖

| 问题 / 依赖 | 待决定或对方提供的内容 | 影响与边界 |
| --- | --- | --- |
| 资料输入 | 首版独立资料格式、大小、正文长度、编码与来源类型 | 现有建议为文本／Markdown 和授权课程图文；未经确认不能开放任意格式或 URL |
| 资料保留与质量 | 原件／版本／派生数据保留期限、可用于质量核验的代表性样本 | 没有依据时不承诺检索准确率或容量 |
| [账号需求](./002-账号与访问控制需求记录.md) | 当前身份、邮箱资格、角色和停用状态 | 维护角色不等于任意知识库或课程的访问权 |
| [课程需求](./003-课程与媒体学习需求记录.md)与[交易需求](./004-交易退款与权益需求记录.md) | 授权课程来源和当前课程访问结论，区分停售、撤回与退款撤权 | 登记资料的维护权限不能透传给所有学员；普通停售保留合法已购知识访问 |
| [Agent 需求](./007-通用Agent与联网问答需求记录.md) | 已发布实例允许的知识集合、当前提问者和问答流程 | 本域提供证据与引用，不直接输出绕过每答联网的正常答案 |
| [模型与费用需求](./008-模型接入与AI费用治理需求记录.md) | 允许的 embedding／模型能力、付费调用准入与核对 | 费用能力就绪后才能付费索引或查询；缺预算显示暂停，不先调用再补费用 |

具体解析器、检索方式与 embedding 模型属于实施前技术验证，不因拆分需求默认选用独立向量服务。
