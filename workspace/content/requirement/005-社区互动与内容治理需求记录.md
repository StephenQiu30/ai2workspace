## 1. 背景与问题

用户希望课程平台同时承担学习交流：学员能围绕课程或独立话题提问、回复、表达反馈，管理自己发表的内容；运营人员能处理举报和必要通知。只有课程播放而没有讨论和反馈，无法完成用户要求的交流闭环。

上述问题来自产品规划，尚无真实社区活跃度、举报量或用户访谈数据。当前工程仅有技术基线，社区功能未实现；不能将知识库网站的文档搜索或导航当作业务社区。

## 3. 目标与范围

首版目标是让已验证账号完成“发起讨论 → 回复交流 → 表达反馈／收藏 → 举报与处置”的闭环，并确保他人内容、课程受限内容及通知收件人不会越权。

| 范围 | 内容与边界 |
| --- | --- |
| 首版已确认 | 独立帖子、课程讨论、评论及单层回复的创建／查看／修改／删除；赞、踩、取消；收藏及取消；必要站内通知、举报与管理员处置 |
| 已确认权限 | 邮箱验证后互动；作者管理自己的内容；游客只看标题、作者昵称、分类、时间和独立公开摘要，正文与评论登录后查看；课程讨论另需当前课程访问权 |
| 后续范围 | 关注与私信已识别但没有交付版本；不为它们提前实现关系链或消息基础设施 |
| 尚未纳入 | 实时群聊、复杂推荐、星级课程评价、任意附件上传；已确认正文图片不等于开放任意文件 |
| 已确认展示与编辑 | 按时间排序、分页；帖子／回复互斥赞踩、收藏仅帖子；Tiptap 帖子正文支持标题、列表、引用、链接、代码、图片，评论精简 |
| 待确认细节 | 正文长度与图片输入限制、评论精简工具集合、删除恢复与保留期限、具体分页大小 |

本域只处理社区内容及站内通知。账号验证邮件由账号领域负责，订单与退款事实由交易领域负责，课程正文与交付状态由课程领域负责；社区内容不会自动成为可信 RAG 资料。
