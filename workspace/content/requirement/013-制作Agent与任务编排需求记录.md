## 背景与来源

用户希望通过学屿学习搭建 Agent 平台、RAG 和多 Agent 编排。制作人员需要能修改剧本、分镜与校验建议，并在模型失败或成本超限时继续自己的工作。旧问答专题提供配置和运行基础，本需求面向作品制作任务。[通用Agent与联网问答需求](./007-通用Agent与联网问答需求记录.md)

| 来源 | 内容 | 性质 |
| --- | --- | --- |
| S-01 | 2026-11-26 用户说明「我的目的是借助这个平台来学习如何搭建一个agent平台，多agent编排，rag等等服务」 | 已确认目标 |
| S-02 | 同日用户要求「明确首版的页面、从剧本到成片的流程、Agent 和 RAG 的职责」 | 已确认范围 |
| S-03 | 同日讨论建议由编剧、分镜和校验 Agent 分工，作者确认后推进 | 首版方案建议 |

## 业务规则与约束

创作者可从剧本、分镜和审片触发约定的任务，并在权限内选择候选结果。付费步骤使用已核准的模型和预算，正式定稿、发布和交易由相应人员及业务入口确认。

## 功能性需求

| ID | 用户需要的结果 | 来源 | 首版范围与状态 |
| --- | --- | --- | --- |
| R-01 | 创作者能在制作步骤发起编剧、分镜或校验任务，取得可编辑、可采纳的候选结果 | S-01、S-02、S-03 | 首版拟纳入 |
| R-02 | 创作者或审片人能查看运行用了哪个输入版本、引用了什么、在哪一步失败并恢复 | S-01、S-03 | 首版拟纳入 |
| R-03 | 运营者能限制各项付费生成并核对用量，超限或结果未知时制作状态可理解且可追踪 | S-02；现有费用治理方向 | 首版拟纳入；额度与供应商待定 |

## 非功能性需求

S-04 为 2026-11-26 用户要求需求至少包含功能性与非功能性需求。下表按本专题风险细化验证条件，定量指标随样片或试点数据评审。

| ID | 质量属性与适用场景 | 可验证结果 | 来源与状态 |
| --- | --- | --- | --- |
| NFR-01 | 模型权限限制 · 外部参考或模型候选包含越权指令 | 模型输出只能进入允许的候选通道，正式内容、发布与交易由对应用户和接口控制 | S-04；验收口径待评审 |
| NFR-02 | 费用与可恢复性 · 重复点击、取消、网络中断或上游结果未知 | 重复触发不重复产生外部请求，未知费用可追踪，手工制作仍可用 | S-04；验收口径待评审 |
| NFR-03 | 执行可观测性 · 审片人员查看候选，运营核对失败运行 | 可追查步骤、版本、引用和费用状态，日志与页面不泄露密钥或受限资料 | S-04；验收口径待评审 |
