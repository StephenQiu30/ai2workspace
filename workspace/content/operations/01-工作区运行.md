# 工作区运行

## 本机入口

在项目根目录安装 `pnpm --dir workspace install --frozen-lockfile` 后执行 `pnpm dev`。默认 http://127.0.0.1:1140/，使用 Node.js 24 和 pnpm 12.4.2。

正式预览执行 `pnpm build` 再 `pnpm start`。开发与正式预览择一占用 1140。启动前核对端口占用，不终止其他项目的进程。

```bash
pnpm --dir workspace install --frozen-lockfile
pnpm build
pnpm start
```

## 检查

从根目录执行 `pnpm lint`、`pnpm types:check`、`pnpm format:check`、`pnpm build` 和 `pnpm test:e2e`。浏览器测试默认启动已构建的站点；已有预览可设置 WORKSPACE_TEST_URL。

## 配置

当前无需环境变量、数据库或外部搜索服务。精确依赖、命令与部署边界由根 PROJECT.md 和 workspace/README.md 维护。

## 部署与恢复

部署使用标准 Next.js；平台 Root Directory 为 workspace。生产托管、访问范围与远端资源等待单独确认。本机预览不代表发布。
