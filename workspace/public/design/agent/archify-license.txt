## JetBrains Mono

Delivered Archify viewer artifacts embed the JetBrains Mono variable font
subsets served by Google Fonts. For characters covered by these subsets, font
selection does not depend on a network request or a locally installed copy.
Uncovered characters (including CJK) still use the system fallback stack;
browser and operating-system rasterization can differ.
JetBrains Mono is maintained at
[github.com/JetBrains/JetBrainsMono](https://github.com/JetBrains/JetBrainsMono)
and is distributed under the SIL Open Font License 1.1. The complete license
text is preserved in `assets/JetBrainsMono-OFL.txt` in the packaged Skill and
in the font CSS carried by standalone HTML and SVG exports.

## Pele

The explainer renders Mermaid chart fences with an unmodified subset of
[Pele 1.3.0](https://github.com/obsidianmd/pele), copyright (c) 2026 kepano,
distributed under the MIT License. The subset and its license text are in
`explainer/vendor/pele/` in the packaged Skill. Charts are rendered to static
SVG when a page is built; delivered pages contain no Pele code.

## Code Analysis external diagnostics

The Code Analysis module includes the unmodified
[OASIS SARIF 2.1.0 schema](https://github.com/oasis-tcs/sarif-spec/blob/1742a253eb654bf8a4ed7c60eaef7412b2c23553/sarif-2.1/schema/sarif-schema-2.1.0.json)
from revision `1742a253`. Its repository content is governed by the
[OASIS license terms and policies](https://github.com/oasis-tcs/sarif-spec/blob/1742a253eb654bf8a4ed7c60eaef7412b2c23553/LICENSE.md),
including RF on RAND Terms Mode. The original terms are preserved in
`modules/code-analysis/import/vendor/OASIS-LICENSE.md` in the packaged Skill.

The line-context fingerprint algorithm is adapted from
[github/codeql-action](https://github.com/github/codeql-action/blob/592d162ba3b2f5a3411d2cbf01df9f82c492f269/src/fingerprints.ts),
revision `592d162b`, copyright (c) 2020 GitHub, under the MIT License.
The complete license is preserved in
`modules/code-analysis/import/vendor/CODEQL-LICENSE.txt` in the packaged Skill.

[three.js](https://github.com/mrdoob/three.js) r128 (`three@0.128.0` on npm,
`build/three.min.js`), copyright 2010-2021 three.js authors, under the MIT
License. It is embedded in the analysis page and runs only when Atlas 3D is
opened. The complete license is preserved in
