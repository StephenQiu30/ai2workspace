# 项目能力

## 当前能力

- 需求与来源维护：保留原话、稳定 ID、确认结论与待定边界。
- 技术设计：按八节模板说明职责、取舍、边界和技术验收。
- 文档实现：使用官方 Fumadocs 与普通 Markdown，保持导航、相对链接和稳定 ID 一致。
- 验证与交付：按真实环境记录命令、结果、限制与 Git 状态。

具体工具或外部 Skill 需要实际可用时读取其规范，不把本页当作工具安装清单，也不宣称已集成业务 Agent 或自动执行。
