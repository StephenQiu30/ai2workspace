# 研发空间

profile: development 在 [普通知识空间](./generic.md)上启用研发场景的约定。工程、检查和任务由空间显式声明，本页不构成额外运行时配置。

需求和明确确认进入产品范围与验收，设计与测试引用对应依据。普通资料不要求完整研发文档链，小修复按实际需要记录。适用工程规则来自该空间的 instruction 来源；本服务根规范只约束本服务自身。

Harness 使用 Context 的资料选择，固定任务依据；在目标工程执行声明的检查，保留候选、工具、公开环境、输出与产物证据。验证和交接不能从文字主张推断完成。Codex 发起任务，网页只阅读、配置与展示结果。

任务样例见 [Harness 模板](../../../templates/harness/README.md)，操作见 [本机使用与交接](../02-本机使用与交接.md)。
