# 职责重构实施与验证

2026-11-15，按用户明确授权在当前未提交工作区实施；不提交、不推送、不发布。职责依据见 [职责与文档归属](../architecture/03-职责与文档归属.md)，旧文档身份对照见 [迁移清单](../architecture/04-文档迁移清单.md)。

## 实施结果

- 服务自身资料由 knowledge 迁至 docs，分为 product、architecture、guides、development、archive；保留原有 29 个文档 ID 和阅读地址。
- profiles 说明归入指南；实际模板按 workspace、knowledge、harness 分组；模板正文只保存一份，旧模板 ID 保留为使用入口。
- Core 按 Workspace、Knowledge、Context、Harness 分域，应用使用命名领域 API；旧公共入口和已有持久化字段保持兼容。知识域使用窄存储接口，不调用任务或进程。
- Context 的显式资料选择可独立使用；Harness 负责工程现场、任务快照、检查、验证与交接，保留原选择约束和真实证据语义。
- 网页使用官方 Fumadocs 目录树，目录标题和顺序来自知识修订中的 metadata，适用规范单独呈现。内部文件始终保留来源命名空间，主知识来源只在展示树中展开。
- 知识修订同时保存来源展示描述；没有采集这些字段的旧索引保持兼容读取，不能补造当时不存在的历史导航记录。

## 数据保留

迁移前记录 202 个既有持久对象摘要。目录大小写变更后的 owner 路径在确认属于同一目录后修复；当前索引指针正常更新。旧 self-operations-guide 的状态、共享合同、TaskOrigin、快照、运行、检查点保持原始字节。旧依据和候选可能已过期，保留历史不表示旧检查仍证明当前源码。

新任务 responsibility-refactor 的合同、检查与交接以 CLI TaskState 和私有证据为准，不在本页手填实时进度。旧任务不由本轮重新完成或自动重建基线。

## 验证范围

- Core 回归包含旧身份移动、历史修订读取、独立上下文选择、确认约束和领域依赖；CLI 包含配置、生命周期、失败/过期、并发与初始化；Web 单测包含真实目录树、来源命名碰撞和来源展示的修订固定。
- 14 项浏览器回归已通过，包含原有阅读、搜索、图片、配置、失联、安全、移动端，以及本轮中文分类、旧地址、历史目录和模板指南跳转。
- 正式构建与 lint、格式检查通过；打包 trace 检查未包含私有运行数据。最终类型检查和全包单测由本轮 CLI 声明检查采集。
- 独立审阅发现的命名碰撞和历史展示依赖当前来源问题，均先复现失败再补回归修复；指南指向和已发布来源范围同步修正。

以上为本机验证，不代表远端 CI、生产发布或真实新 Codex 会话验收。人工验收/例外、私有环境、报告导入等既有后置范围未扩大。
