# 普通知识配置兼容说明

当前产品是项目内 Workspace 模块，采用 development。此页仅解释已有 generic 数据的兼容读取，不作为通用服务建设或创建入口。

profile: generic 面向普通资料。无需 Git、工程、检查、编号或 PRD。profile 是 Core 内建的适用类型，本页是解释，不是可安装或执行的规则包。

- 知识来源保留原目录和所有权；扫描不执行正文命令。
- 使用空间、来源、文档三层身份；路径和编号不承担身份。
- 治理注记保留决定来源，确认绑定正文摘要；新正文不继承旧确认。
- 阅读和资料选择可独立使用，不要求创建研发任务。
- 适用 instruction 由当前空间显式绑定，不能自动继承 ai2workspace 自身的工程规范。

配置参考 [空间模板](../../../../harness/templates/workspace/README.md)。
