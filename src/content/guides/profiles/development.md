# 项目研发配置

当前项目 Workspace 模块采用 profile: development。工程、检查和任务由当前项目显式声明；[generic](./generic.md)仅保留旧数据兼容。本页解释配置，不构成额外运行时策略。

需求和明确确认进入产品范围与验收，设计与测试引用对应依据。普通资料不要求完整研发文档链，小修复按实际需要记录。适用工程规则来自该空间的 instruction 来源；本服务根规范只约束本服务自身。

Harness 使用 Context 的资料选择，固定任务依据、角色与策略快照；当前项目策略要求显式角色、精确输出与必需检查。校验实际变更范围，在目标工程执行检查并保留候选、工具、公开环境、输出与产物证据。验证和交接不能从文字主张推断完成。Codex 发起任务，网页只阅读、配置与展示结果。

任务样例见 [Harness 模板](../../../../harness/templates/tasks/README.md)，操作见 [本机使用与交接](../../../../src/content/guides/02-本机使用与交接.md)。
