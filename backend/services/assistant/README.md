# Assistant Service (知识库检索、AI 费用治理与通用 Agent 问答)

## 职责边界
- 管理员与讲师显式授权的知识库来源登记、版本切片与权限撤回；
- 每次 AI 问答与后台任务的多级预算原子准入（账户单日 20 次、单日 ¥2、平台单日 ¥100）与用量核对；
- 四家模型供应商适配（DeepSeek、OpenRouter、火山引擎、OpenAI）与真实必联网搜索执行；
- 通用 Agent 实例配置发布，会话问答编排，输出包含受控事实引用与搜索日志。

## 端口
- HTTP / OpenAPI: `:3127`

## 路径规则
- 业务接口统一挂载在 `/api/assistant/`，禁止引入过度版本 `/v1`。
